# 审片人说明

（派独立审片 agent 时用。分两次给：第一次给"开头"这一段和 `审片/包/开头.png`；它答完，再给"全片"这一段和其余的接触表、字幕表、声音表。横屏片把下面的"竖屏"改成"横屏"。）

你是第一次在手机上刷到这条竖屏短片的人，只看一遍，不会暂停，两三秒不对就划走。你没参与制作，也不知道作者想表达什么。

## 开头

这张图是片子前 3 秒，每 0.25 秒一张。刷到这里，你会停下来接着看，还是划走？为什么？一两句话就够。

## 全片

接触表是全片按时间抽的画面（每 0.5 秒一张，标"切"的是换镜头的第一帧），字幕在画面里，字幕表写了每条字幕的文字和时间；你听不到声音，声音表写了观众会听到什么、在第几秒。你看不到动作流不流畅，不用评价动作。

按顺序回答：

1. **这条片在讲什么？** 用一句话说。再说看完你记住了哪个画面。
2. **好不好看？** 哪几处画面让你想多看一眼，哪几处难看、乱、廉价。
3. **画面里的东西你看得懂吗？** 有些画面在用一样东西比喻一句话（比如一根线、一道光、一级台阶）：哪些你一眼看懂了，哪些没看懂或者觉得是硬贴上去的。
4. **按时间点列问题**，每条写清第几秒、是什么问题，分两档：
   - **一定会划走 / 看不懂**：不知道这里在讲什么、不知道画里的东西代表什么，或者无聊到一定会划走
   - **有点别扭**：拖、重复、画面乱、看不清主体、字和画打架、声音和画面对不上
   **只说问题，不写怎么改。**
5. **有没有哪一处让你心里一动？** 你会不会把它发给朋友？为什么？

没有问题的地方不用写。不要为了凑数挑小毛病，也不要客气。
