# 参考：字幕和画里的字

代码在 `引擎/subs.js`，版式（尺寸、安全区、字号、默认位置）只写在 `脚本/画幅.py` 一份。

## 字幕要好看

字幕是观众全程盯着看的东西，丑了整条片都掉价，而且只要位置对、读得完，检查是查不出丑的。

- **行尾不留句号、逗号、顿号、分号、冒号**：字幕靠断行和停留表达停顿，行尾的标点只是噪音。句中停顿用空格；问号、叹号带语气，留着。这只是排版，不算改说法。
- **字要有轻重**：一句最多一个强调词，只给这句里真正要砸下去的词；颜色有固定含义（`MEANING`），同一个颜色全片说同一件事，观众看几次就学会了。亮度也要拉开，只差一点色相的强调在手机上看不出来。
- **阴影要真能托住字**：贴着字、看得出来。对比度检查仍只量字和背后的画面，不算阴影，不能靠阴影把字放进乱处。
- **字幕的颜色从片子的色板来**：纯白常常浮在画面上，略带底色的亮色更贴这个世界，强调词再用最亮的。

## 字进世界

判断标准：**字的行为要演出这句话的意思**。说"挡在外面"的字就真的进不去，说"循环"的字就绕成圈。换一条片还能照用的做法（通用的飞入、弹跳、描边）不算进世界，只是特效。

- 每场想一次：这句的关键词能不能变成这个世界里的东西（被光照到、被风吹、落在地上、跟着物件一起动）。不必句句都做，也不凑数；全片一处都没有时，所有字就都一个样子。
- 观众不用停下来辨认：盖住画面也读得出这几个字，放完还觉得它本来就在那里。
- 卡里写 `字幕处理：关键字代替`，这张卡不出字幕，字全部自己画。句子的其余部分用 `TEXT.说(c, 字, x, y, { 字号, 色, 对齐, 淡, 名 })`，字体、字距、阴影和字幕一样，观众才知道还是同一个声音在说话。
- 同样要守读字时间和安全区，用 `TEXT.draw` 或 `TEXT.mark` 登记；登记时要写 `稳`，字还在动、还没读得清的时候不算。
- **字体**：世界字可以用一种片内字体，全片最多一种，和普通字幕的宋体拉开，从画风里选。字体文件放 `片子/<片名>/画风/<画风名>/字体/`，在布景模块里用 `FontFace` 加载（`await 字体.load(); document.fonts.add(字体)`）；用之前查一遍缺字，检查也会列出缺的字。

## 字和时间从哪来

**字和时间只从画面卡和时间轴来**，镜头代码里不写字幕的字。

- 画面卡标题行就是上屏的字：`/` 处断行，【词】是强调词（【词|颜色名】用颜色含义表里那种颜色）；没有字幕的卡写"（无字幕）"。
- `代码/时间轴.json` 里每个镜头写上属于哪张卡：`{ "id": "A1", "from": 0, "to": 4.5, "卡": "1" }`。字幕从这张卡第一个镜头开始，到最后一个镜头结束。每次渲染都直接读画面卡。
- 断行：每行最多 16 字，最多两行；在标点和词组之间断开，不拆词组，不让一行只剩一两个字。放不下就在原有的停顿处拆成两条。

## 版式（按画幅）

| | 横屏 1920×1080（默认） | 竖屏 1080×1920 |
|---|---|---|
| 普通 | 54px，字多时最小 46px | 58px，最小 52px |
| 问句、结论、落点 | 64px | 70px |
| 引文、出处 | 46px | 50px |
| 概念巨字（画里的字） | 160–300px | 120–220px，占画面宽 50–80% |
| 默认位置 | 下方，字幕块中心在 85% 高 | 下方，73% 高 |
| 安全区（不放字） | 顶部 7%、底部 7%（平台进度条）、左右各 8% | 顶部 12%、底部 20%、左右各 6%、右侧按钮列（x > 88%、y 在 45–80%） |

横屏的数是 v4 新定的（《傲慢》720p 下 36px 等比放大），竖屏的在手机上实测过。

**颜色**：底亮用深字，底暗用浅字；默认取 `代码/色板.js` 的 `window.SUB_STYLE = { 字, 强调, 心里话 }`，强调色每种代表一个固定的意思，和颜色含义表一致。字幕默认带一层贴着字的阴影（浅字配 95% 的黑影、深字配浅影，模糊约字号的 0.2、往下偏 0.05）；改写 `SUB_STYLE.阴影 = { 色, 模糊, 偏移 }`，不要就写 `阴影: false`。

**排版**（`SUB_STYLE` 里写，默认不开）：
- `字距`：每个字之间多空几像素。字幕本身也要好看：横屏 1080p 建议 4（对标的字距明显拉开）。
- `句间留白`：前后两条字幕首尾相接时，后一条晚多少秒出来（建议 0.16），读的人有一口气。
- `出处: '署名'`：引文里「——」开头的出处行改成小号斜体、字距更开、偏暗，主句出齐后再淡入。

## 位置写在镜头里

每个机位一个，换镜头才换；放在这一镜的空处，关键句贴着它说的东西：

```js
SHOT('A2', { 字幕: { y: .16 }, final: ... })                  // 字幕块中心在画面高 16%（主体在下方时放上面）
SHOT('A5', { 字幕: { x: .1, y: .3, 对齐: 'left' }, ... })
SHOT('A6', { 字幕: (lt, x) => ({ y: .3 + lt * .02 }), ... })  // 贴着画里的东西走，每帧移动不超过 6 像素
SHOT('A7', { 字幕: '自动', regions: (lt, x) => ({ 主体: [x0, y0, x1, y1] }), ... })   // 引擎找空处，躲开报告的主体
```

**自动找空处**：引擎在这一镜字幕清楚显示的那一段里，每隔约 0.25 秒试画一帧，在安全区里五个高度（下、中下、上、中上、中）挑最空的：背景起伏小、和底色一样亮、不压主体。平涂的、和背景一样亮的主体认不出来，镜头要报 `regions`（屏幕上的位置，镜头运动以后的）。3D 镜头的主体位置用 `S3.投影` 算。

## 出场的处理

画面卡"字幕处理："写处理的名字，不写就是普通。种类（问句、心里话、引文）管字多大多粗，处理管怎么出来，可以一起写（"引文 浮现"）。

| 处理 | 怎么出来 | 用在 |
|---|---|---|
| 普通 | 整句淡入、上移 16 像素，0.3 秒，先快后慢 | 大多数叙述句 |
| **浮现**（v4） | 一个字一个字由虚变清（模糊 3.2 像素 → 0）、上浮 7 像素，错开 0.024 秒，每字 0.5 秒；退场 0.38 秒平滑淡出 | 整句叙述，柔、有呼吸，长句也不累（《傲慢》） |
| 意群 | 按词组一块块出来，块与块错开 0.16 秒，最多 0.5 秒 | 长句，像被"念"出来 |
| 逐字 | 一个字一个字，错开 0.05 秒，最多 0.6 秒 | 两三个字的概念 |
| 重读 | 整句先出来，【强调词】晚 0.12 秒、用 0.4 秒单独出来（0.9 倍放到 1 倍，字永远不冲过头） | 一句里有一个词要砸下去 |
| 揭示 | 从左往右擦出来，0.45 秒 | 留悬念的句子 |

退场：浮现 0.38 秒，其余 0.2 秒。时间可以在 `代码/色板.js` 改：`window.SUB_TREAT = { 浮现: { stagger: .03 } }`。

**读字下限** = 字数 ÷ 6 + 这条的出场 + 退场 + 句间留白（普通共 0.5 秒）。每秒 6 字是勉强读得完的底线；正常节奏大多给到每秒 4–5 字。

## 画里的字和关键字

| 种类 | 例子 | 怎么做 |
|---|---|---|
| 画里的字 | 招牌、纸条、碑文、手机屏幕 | 画在它所在的那一层，跟着视差动；3D 里画成贴图贴到物体上（纸卡的倒角盒正面） |
| 关键字 | 揭晓的概念名、概念巨字 | 当作画里的东西画，可以用字变形状；揭晓那一下别的东西退场 |
| 强调词 | 句子里重读的一两个词 | 留在字幕里，画面卡写【】 |

观众要读的字用 `TEXT.draw(c, 字, x, y, { 字号, 字重, 色, 种类: '关键字' })` 画；自己画的（字变形状、贴图上的）画完用 `TEXT.mark(c, 字, [x0, y0, x1, y1], { 种类: '关键字' })` 登记，登记过的才被检查。

## 检查（`render.py --check` / `--video`）

| 查什么 | 标准 | 档 |
|---|---|---|
| 读字时间 | 不少于读字下限；画里的字、关键字停稳不少于 字数 ÷ 6 秒 | 硬伤 |
| 行尾标点 | 行尾没有句号、逗号、顿号、分号、冒号 | 硬伤 |
| 断行 | 最多两行，一行不超过 16 字 | 硬伤 |
| 强调 | 一句最多一处 | 硬伤 |
| 安全区 | 字停稳时外框不进安全区（按画幅） | 硬伤 |
| 缺字 | 宋体里没有的字 | 页面报错，不渲 |
| 片内字体缺字 | `画风/*/字体/` 里的字体缺上屏的字 | 说明（候选字体没用上也会列出） |
| 全片没有强调词、没有字进世界 | 至少各有一处 | 说明 |
| 对比度 | 字和背后画面不低于 4.5:1 | 提醒 |
| 跟随速度 | 正在读的字每帧移动超过 6 像素 | 画里的字硬伤，字幕提醒 |
| 压主体 | 字幕压到 `regions` 报告的主体 | 提醒 |
