# 参考：检查和渲染

## 渲染（`脚本/render.py`）

```
uv run --no-project --python 3.12 --with-requirements ../requirements.lock python render.py <片子> --stills A3@1.2,B1 [--out 目录] [--safe]
uv run ... python render.py <片子> --video <输出.mp4> [--from 秒 --to 秒] [--label [详]]
uv run ... python render.py <片子> --check [--from 秒 --to 秒]
```

- 画幅从 `片子.json` 的 `"画幅"` 读（`"横"` 默认 1920×1080，`"竖"` 1080×1920）。
- 走显卡：Edge 加 D3D11，开头打印显卡名；拿到的是软件模拟会提醒（慢二三十倍）。`--cpu` 强制软件模拟，只用来排查。本机 60 秒 1080p 的片子，带全部检查约 10–15 分钟（3D 镜头更重）。
- 页面走本地 HTTP 服务：`/skill/` 是 skill，`/film/` 是片子；镜头代码里用 `SKILL_URL`、`FILM_URL` 拼地址。缺文件（404）直接报错。
- **冻结布局**：`U.freeze('名', () => ...)` 第一次跑时存进 `代码/冻结/名.json`，以后只读这份（取点再随机的布局在显卡和软件模拟下会错位）。
- **镜头标注**：`--label` 顶部压一行镜号、时间码、版本，看片时说得准是哪一镜；`--label 详` 再加卡号、"镜头"和"观众明白"，只给自己逐镜检查用。成片（`<片名>.mp4`）不许带标注。
- 结论写进 `草稿/检查.txt`。只有一定是坏的才算硬伤（退出码 1）；可能出于创作意图的只算提醒，逐条看，故意的写一句理由留着。**检查全过只说明没有技术毛病，不说明好看。**

## 代码动画的毛病（重点）

| 查什么 | 怎么查 | 档 |
|---|---|---|
| 画面自己在抖 | 每个镜头取一帧，先画别的时刻再画回来，不一样（随机数、当前时间、上一帧的残留；3D 的状态没有每帧按 t 重设） | 硬伤 |
| 数值算坏 | 坐标变成 NaN | 硬伤 |
| 露边 | 最远的层没盖满；中、近层贴边的实色边被移进画面 | 硬伤 |
| 凭空出现或消失 | 画面分成 48 块，某一块一帧之内变了很多，前后都不动 | 提醒 |
| 突然跳动 | 从静止突然大幅变化，没有缓入（《傲慢》的灯带比落地晚亮了 0.1 秒就是这个） | 提醒 |
| 僵住 | 镜头里动过，最后 1 秒以上画面完全不变 | 提醒 |
| 切点小跳 | 切点前后画面大部分一样，只有一块变了 | 提醒 |
| 细线闪烁 | 连续半秒有像素亮暗来回翻 | 提醒 |
| 画面停太久 | 约 2 秒几乎没变化，也没有漂 | 提醒 |

镜内硬切（`CAM.切`、`S3.机切`）后的帧按新的一段查，不报跳动。字、摄像机、配乐、音效、质感的检查见各自的参考文档，同在这份报告里。

## 成片文件（`脚本/终检.py`，出完 mp4 自动跑，都是硬伤）

- 规格：和片子的画幅一致（1920×1080 或 1080×1920）、恒定 30 帧、H.264、yuv420p、BT.709 标记、AAC 48k 立体声、码率不超过 12M、能边下边播。
- 编码后的声音峰值不超过 -1 dBTP。
- 光敏闪烁：一秒内大面积明暗或红色交替超过三次（关系到观众的健康，不算创作意图）。

## 一致性（换机器、换显卡、改了引擎以后）

`python 终检.py <新版.mp4> --对比 <上一版.mp4>`：逐帧 PSNR，低于 33 dB 的帧段列出来。这是查"有没有走样"，不是和参考片对标。参考：同一套代码，显卡和软件模拟之间约 40 dB（肉眼看不出）；取点布局没冻结时掉到 27 dB。

## 审片包（`脚本/审片包.py <片子> [--video 成片]`）

存进 `审片/包/`：开头（前 3 秒，每 0.25 秒一张）、接触表（每 0.5 秒一格加每个镜头第一帧）、字幕表、声音表（只写听得到什么）。不给画面卡和意图。用法见 `步骤/4_成片.md` 和 `模板/审片人说明.md`。
