# 参考：音效

汇总和混音在 `脚本/音效.py`（render.py 调用，用 procedural-sfx 的 `mix.py`）；真实录音用 `脚本/素材.py` 找、`脚本/音效加工.py` 做。

## 思路

按"录现场"的思路：画里真的碰到什么，才发出什么声音，加少量为情绪服务的设计声（转场、揭晓）；不做每个动作都配夸张声音的卡通做法。**物理质感的声音用真实录音**（脚步、布料、石头、纸、金属、风、空间），合成只留给 UI 和提示类（气泡、提示音）和低频垫底。

## 真实录音（v4）

1. **找**：`python 素材.py 检索 "footsteps stone stairs" "rubber stamp"`（BBC 音效库 + Freesound 只列 CC0；英文关键词最准）。
2. **下载**：`python 素材.py 下载 <片子> bbc:07004162 freesound:470710`，存进 `草稿/音效/原始/`，出处和授权自动记进 `原始/来源.txt`。
3. **做**：写 `代码/音效素材.json`（格式见 `音效加工.py` 开头），`python 音效加工.py <片子>` 做成 `草稿/音效/素材/<名>.wav`，并量出每条"响起"和"最响"在第几秒（`对齐.json`）。
   - 切、变调、高通、低通、低架、高架、压缩、倒放、电平。
   - **空间**：套真实空间录下的回响（`音效/空间/`：教堂、大厅，CC0），所有声音像在同一个空间里。默认在配方里写一次，风格卡里定。
   - **点**：一条录音里切出很多次（13 声脚步各不一样），每次随机变调一点，重复的声音才不假。
   - **叠**：在主声音上叠别的（脚步落下前 0.17 秒先有一下衣袍窸窣）。
   - **层**：几条录音叠成一条（环境风：沙漠风 + 沙丘 + 天际）。
4. **用**：镜头里标

```js
SHOT('B3', { 声: [{ t: 2.1, 素材: '盖章_0', 增益: .7, x: 900, 对齐: '响起', 让: true }], final: ... })
```

- `对齐`：`'响起'`（默认）t 是声音响起来的那一帧；`'最响'` t 是最响的那一帧（风声、呼啸对准切点）。
- `让: true`：这个声音响时配乐让开 3.5 dB（脚步、落地、盖章这类要听清的瞬态）。《傲慢》v4 的脚步被配乐重拍盖住，就是没让。
- 合成的配方照样能用：`{ t, 类: 'thump', 参数: { f: 60 }, 增益: .2 }`，常用来给录音垫一点低频。

## 环境底

画面卡里场的开头写一行 `环境：风_石原`（素材名，取那条录音的开头一段铺满这一场、首尾淡 0.8 秒；强度当增益），或者 `环境：风`（合成配方，`音效/配方.py`）。现场从来不完全安静，空间感大半靠它。镜内硬切处要换一层环境声的（俯拍时风大一截），在那一镜标 `{ t: 0, 素材: '风_高处', 环境: true }`，从切点那一帧起铺（铺多长在 音效素材.json 里切好，首尾留淡入淡出）。

## 克制和留白

- 重击、呼啸少用，用多了就不重了；两个重击不挤在几帧之内。
- 持续的运动（一直在飘、字在滚）不配声音。
- 音效和画面里碰到的那一帧对齐（画面相对配乐早一帧，音效不跟着提前）。
- 左右按 `x` 只轻轻分开（手机外放大多是单声道）；远的层声音小。

## 授权（规矩 10）

## 混音和试听

渲视频时自动混好：音效 + 环境底 + 配乐（闪避 3.5 dB），整片统一到 -14 LUFS、峰值 -1 dBTP。报告在 `草稿/音效/混音报告.txt`；可能被盖住的列成提醒（低频垫底被盖住是预期的）。**没经人耳听过的声音**（新配方、所有加工过的录音）列在 `草稿/试听/试听表.md`，交片时请用户听。

## 检查

| 查什么 | 标准 | 档 |
|---|---|---|
| 声音标错 | 时间超出了它所在的镜头；用的素材没做 | 硬伤 |
| 峰值 | 超过 -1 dBTP | 硬伤 |
| 重击挤在一起 | 两个重击在几帧之内 | 提醒 |
| 可能听不见 | 混音时被更响的声音盖住 | 提醒 |
