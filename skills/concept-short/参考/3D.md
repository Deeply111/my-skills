# 参考：3D 层

代码在 `引擎/3d.js`（three.js r160，`引擎/第三方/three/`，MIT）。**每条片都加载**；镜头写了 `三维:` 才渲 3D，不写不多花时间。出自《傲慢》。

## 3D 和 2D 怎么分工

| 用 3D 更好 | 为什么 | 《傲慢》里的例子 |
|---|---|---|
| 空间和布景：地面、台阶、高台、房间 | 透视、遮挡、投影都是真的，机位一动就对；2D 分层视差只能假装 | 台阶、高台、三层圆台 |
| 光：光柱、聚光、阴影、落地光、逆光 | 光被挡住、照出体积、投出跟着动的影子 | 体积光柱、人投在台上的影子 |
| 材质：石、金属、纸板的厚度和倒角 | 光扫过时法线和粗糙度会变 | 实拍石材、金冠、纸卡的倒角 |
| 穿过空间的运镜：环绕、俯拍、贴地低机位 | 透视随机位变化；2D 推拉只是放大 | 环绕升起、台阶顶俯拍、镜子的低机位 |
| 有体积的比喻：从地里长出来、变形、反射 | 长出来时有遮挡、影子、落地的分量 | 台座、台阶升起、天平、镜子里没有冠 |
| 人物站在场景里 | 和地面接触、被光照、被遮挡 | 绑骨人物（`脚本/blender/绑骨人.py` 建模，动作捕捉驱动）；不动的人物仍可用兜帽人（`人形.py`） |
| 雾的层次 | 雾有前后，能把远处吃掉 | 低雾、远景雾 |

| 用 2D 更好 | 为什么 |
|---|---|
| 所有的字（字幕、标题、纸卡上的字） | 要锐利、可读、排版可控；纸卡本身可以是 3D，字画成贴图 |
| 比喻线和图形符号（线、箭头、括号、光团） | 要干净、像"画上去的意思"，和布景分开 |
| UI 道具（手机、聊天卡、排行榜） | 本来就是平面的 |
| 风格化的形象（侧脸、符号化的脸） | 3D 写实反而失去风格，规矩 2 也不许写实的脸 |
| 精细的粒子和碎屑、成千根线的图形动画（线光字） | 2D 便宜、可控 |

**后期链**（`引擎/3d.js`，每个 3D 镜头都过）：渲染（4× MSAA）→ 环境光遮蔽（N8AO）→ 景深 → 泛光 + 色调映射（AgX）→ SMAA 抗锯齿，用 pmndrs postprocessing（Zlib）。MSAA + SMAA 管细边：纸卡、栏杆的棱推拉时不再一闪一闪。之后才是 2D 叠加和成片质感（`finish.js`，含查找表调色）。

**素材从哪来**：材质、HDRI、模型只从 Poly Haven、ambientCG 拿（都是 CC0，可商用、不署名），用 `脚本/三维素材.py 检索 / 下载`；材质和 HDRI 进 skill 的 `素材/`（每条片都能用），模型进片子的画风。默认 1k，占半个画面以上的地面和墙用 `--尺寸 2k`。人物动作例外：来自 Mixamo，存在 `素材/动作/`（`脚本/动作库.py`，不是 CC0，见 `SKILL.md` 规矩 10）。

**混合**：3D 先画空间和实体 → 2D 叠字、线、UI（`S3.投影` 贴着 3D 里的东西走）→ 统一过成片质感 → 字幕。只有整条片的画风本身是纯平面（水墨、线稿、扁平 MG）时才整片不用 3D，第 2 步说明为什么。

**代价**：3D 调机位和画幅比 2D 贵；人物要 Blender 建模；要显卡（本机 VMware 虚拟显卡走 D3D11 可以，1080p 一帧约 0.3–0.5 秒，含检查）。

## 写法

**布景**写在 `代码/三维/*.js`（这条片的）或 `画风/<名>/三维/*.js`（画风的，先加载），是 ES 模块，按文件名顺序加载。布景注册时立刻执行，后面模块定义的东西这时还不能用；共用的工具放最靠前的文件。镜头脚本先于 3D 引擎加载，顶层不能用 `S3`、`V3`、`THREE`：

```js
const { THREE, V3 } = S3;
const 人 = await S3.模型(FILM_URL + '画风/暗场/模型/人.obj');      // 顶层 await：下一个模块加载时已经好了
S3.布景('台阶', async g => {
  const ground = new THREE.Mesh(new THREE.CircleGeometry(80, 64), await S3.石材(0x70757e, 26, 26, 'rock_face', 1.6));
  ground.rotation.x = -Math.PI / 2; ground.receiveShadow = true; g.add(ground);
  S3.雾团(g); S3.低雾(g); g.光 = S3.光(g);
});
```

**镜头**（普通脚本）：

```js
SHOT('S7', {
  字幕: { y: .16 },
  三维: (lt, x) => { S3.显示('台阶'); S3.环境(.8);
    const S = S3.布景们.台阶; S.光.set(V3(0, 0, 0), .55, .8);
    S3.机切(lt, [0, t => S3.机(V3(-1.9, 1.3, 5.4), V3(1.2, 1.4, 0), { 光圈: .4 })], [5, t => S3.机(V3(10.2, 6.9, 3.1), V3(1.4, .9, 0), { 视角: 40 })]); },
  final: (c, lt, x) => { const p = S3.投影(V3(-1.2, 1, .75)); MG.长线(c, [p.x, p.y], ...); },   // 2D 叠加，可以不写
});
```

**每帧必须按 t 重新设所有状态**（位置、缩放、可见、亮度），不靠上一帧：`renderAt(t)` 是纯函数，检查会先画别的时刻再画回来比。

## 工具

| 名字 | 是什么 |
|---|---|
| `S3.布景(名, async g => {})`、`S3.显示(名)`、`S3.布景们.名` | 布景组预先建好，每镜只显示自己那组 |
| `S3.机(位置, 看向, { 视角 34, 对焦, 光圈 .35, 呼吸 1, 冲击, 滚 })` | 摆一个固定机位；呼吸 1 = 距离 × 0.13% 的极轻手持感；光圈 0 不虚 |
| `S3.运镜(lt, 基, [动作…], { 时长, 光圈, 对焦 })` | 运镜预设：推拉、横移、升降、摇、俯仰、滚、变焦、环绕、漂（`参考/镜头.md`）；相机挂在 three-story-controls 的支架上 |
| `await S3.相机动画(名, 地址)`、`S3.播相机(名, lt, { 看向, 光圈 })` | Blender 打的相机路径（`脚本/blender/相机.py` 导出的 .glb），按时间播 |
| `S3.机切(lt, [起, t => {}], ...)` | 镜内硬切，每段 t 从段头算 |
| `S3.冲击(t, t0, 幅度)` | 落地那一下的衰减抖动（给 机 的 冲击） |
| `S3.投影(V3)` | 3D 点 → 画面像素 `{ x, y }` |
| `S3.环境(k)`、`S3.泛光(强, 半径, 门槛)` | 默认环境光整体调亮暗；泛光（默认 .55, .55, .8，mipmap 泛光，光晕柔、不糊成一团） |
| `S3.遮蔽(强, 半径, 衰减)`、`S3.遮蔽默认({ 半径 })` | 环境光遮蔽（N8AO）：缝里、接触处、物体脚下自然变暗，质感不平。半径按米，**按布景尺度定**：桌面小场景 .1–.2，房间、台阶 .5–1；每帧复位到默认，镜头里可改；强 0 关 |
| `S3.色调('AGX' \| 'ACES')` | 色调映射，整条片定一次。默认 AgX（高光过渡自然，亮处不发青发黄）；ACES 更艳更硬（《傲慢》） |
| `g.环境图 = await S3.环境图(名)` | 实拍 HDRI 当这个布景的环境反射（`素材/环境/<名>.hdr`，Poly Haven CC0）：金属、纸、陶土、木头的高光映着真实的房间。只管反射不当背景；不写的布景用默认的暗渐变球。现有：studio_small_08（柔光棚）、brown_photostudio_02（室内，暖）、fireplace（夜里壁炉，暖）、small_empty_room_1、moonless_golf、kloppenheim_02、dikhololo_night（夜）、kloofendal_overcast_puresky（阴天） |
| `await S3.材质(种类, { 平铺, 色, 法线, 粗糙, 金属, 反射, 遮蔽, 物理 })` | 实拍 PBR 材质（`素材/材质/`，Poly Haven、ambientCG CC0，清单在 `索引.json`）：纸 Paper001/003、纸板 Cardboard002、木 wood_table_worn/oak_veneer_01/Wood051/wood_table_001、布 fabric_pattern_07/Fabric086、石膏墙 painted_plaster_wall/white_plaster_02、金属 Metal049A/Metal032/rusty_metal_02、地面 concrete_floor_worn_001，加原来的三种石材。平铺按真实尺寸算（木板一块多宽、人多高） |
| `await S3.gltf(地址)` | Poly Haven 的道具模型（glTF，自带材质），`脚本/三维素材.py 下载 模型` 下到片子的画风里；道具要从场景里长出来（规矩 9），不拿现成模型硬塞 |
| `await S3.文字(字, { 字号, 色, 字重, 宽, 行距, 字距, 描边 })` | 3D 里的字（troika，SDF）：纸卡、招牌、墙上的字近看也锐利，不再画在贴图上糊掉。字体是 skill 的思源宋体；只在布景里建一次，不按帧改字 |
| `await S3.回放(地址, { 材质: (名, o) => 材质 })` → `.到(t)`、`.物体[名]`、`.时长` | Blender 里算好的刚体、布料模拟（`脚本/blender/模拟.py` 烘焙）按 t 回放：纸卡塔塌、东西散落、布盖下来。两帧之间插值，跳到任意 t 都一样 |
| `S3.光(g, { 色, 柱色, 高 })` → `.set(落点, 亮度, 宽度, 张角)` | 聚光灯 + 体积光柱（光线步进，带流动的烟）+ 柔边落地光 |
| `S3.浮尘(g)` → `.set(落点, t, 亮度, 宽度)` | 光束里的浮尘 |
| `S3.雾团(g, { 种子, 个数, 近, 远, 色 })`、`S3.低雾(g, { 色, 浓 })` | 远处一圈雾团、贴地两层低雾，按 t 漂 |
| `await S3.石材(色, 平铺x, 平铺y, 种类, 法线)` | 石材（《傲慢》的写法，等于 `S3.材质`）：`cracked_concrete`、`rough_concrete`、`rock_face` |
| `S3.倒角盒(宽, 高, 深, 倒角)` | 带倒角的方块几何体 |
| `await S3.人物(地址, { 双面, 附件 })` → `.载动作(名)`、`.捕(名, 选项)`、`.串([段...], { 过渡 })`、`.摆(动作, t)`、`.关节` | 绑骨人物（`.glb`，骨名见 `脚本/blender/绑骨人.py`）。`动作` 是 t 的函数：`人.捕(...)` 用动作捕捉，或者自己返回 `{ 盆, 盆转, 腰, 胸, 颈, 头, 脚L, 脚R, 手L, 手R }`（手写时脚和手给目标点，两段反解）。下摆、围巾这类造型特有的骨写在 `附件({ p, D, J, 腿角, 前, 再前, P, 方向, 对向, E, V })` 里：改 `D[骨名]`，`前`、`再前` 是 .1、.2 秒前的解，用来算迟滞；没写的骨跟父骨转。怎么选动作见 `参考/动作.md` |
| `await S3.模型(地址, { 遮蔽拉开 })` | 读 Blender 导出的 OBJ（阴影在顶点色里），按分位数拉开对比 |
| `S3.摆动(材质, { 高, 幅 })` | 布料轻摆（越往下摆幅越大） |
| `S3.镜面(g, { 半径, 位置, 藏: [物体], 亮 })` → `.淡(k)` | 软边、可淡入的实时镜面；藏里的物体不出现在倒影里 |
| `S3.平铺噪声(N, 种子, 层数, 周期, fn)` | 可平铺的分形噪声画布（云、雾、光圈的质感） |
| `S3.THREE`、`S3.scene`、`S3.camera`、`S3.renderer` | 直接用 three.js |

## 经验（《傲慢》）

- **镜面**要比地面高一点（默认 .012），不然从地下的虚拟机位往上看会被地面挡住；倒影里看得到多远，取决于镜面伸到多靠近镜头。贴地低机位看倒影最清楚。
- 体积光柱贴地那一截自动收掉，不糊住人；人身上的亮交给聚光灯和落地光。
- 雾团不旋转，旋转会拉出条纹。
- 运镜和转场的目标见 `参考/镜头.md`。
- 被光照到的袍子别加太多自发光，会像塑料。
- 模型和大运镜用 `脚本/blender/`（`说明.md`）：建模、烘焙阴影、打相机路径在 Blender，渲染在 three.js。
- 动作用 GSAP 的曲线和时间线（`参考/动作.md`），运镜有 `S3.运镜` 和 Blender 路径可用，调手感比手写缓动方便。
- 掉落、倒塌、散开、布盖下来这类有物理的动作，曲线手写不如模拟自然：在 Blender 里搭刚体或布料，`模拟.py` 烘焙，`S3.回放` 按 t 读（`脚本/blender/说明.md`）。

## 经验（《拖延》，v4 第一次用新的后期链）

- 发光的纸条不要用自发光材质 + 近处点光 + 泛光三样叠：在 ACES 下糊成一团白。换成颜色受控的 MeshBasic，亮度自己算。
- AgX 比 ACES 灰、淡，暖色会被压一点：要暖靠灯色、HDRI 和查找表，不靠把饱和拉高。
- 遮蔽半径照默认（.5）放在小桌面场景上会把整片桌面压脏：小场景用 `S3.遮蔽默认({ 半径: .12 })`。
