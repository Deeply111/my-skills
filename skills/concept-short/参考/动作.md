# 参考：动作和动画好看

动作预设在 `引擎/motion.js`（`动.xxx`），MG 基础工具在 `引擎/lib/mg.js`（`MG.xxx`）。

## 动画好看（目的第 1 条的一半，和画面好看并列）

| 方面 | 要做到 | 常见的毛病 |
|---|---|---|
| 曲线 | 每个动作都有加减速，到位时刹得住；弹性只用在该弹的东西上 | 匀速滑动（机械）、全片同一条缓动（腻） |
| 时间和间距 | 快慢有对比：快的利落、慢的沉；停顿给足 | 所有动作一样长、一个接一个没有呼吸 |
| 预备和跟随 | 动之前先反向收一下，停下后有余波（袍摆、链子晃两下） | 突然开始、突然停死 |
| 分量 | 重的东西慢起、重落、带一震；轻的东西飘 | 什么都一样轻，像纸片 |
| 弧线 | 生物和抛起来的东西走弧线 | 走直线 |
| 一次一件事 | 同一时刻只有一个主要动作，视线不被抢 | 几样东西同时动，不知道看哪 |
| 跟音乐 | 落点卡拍，大动作在强拍；有意错开的地方要少 | 拍子乱，或者每下都卡拍变成机械 |
| 衔接 | 镜头之间动作接得上（在动作上剪），转场有方向 | 切过去动作断了、跳了 |
| 活着 | 静止的东西也有极轻的呼吸，雾在流，光在微动 | 定格的死帧 |
| 统一 | 一条片一套运动规范（`运动.js`），手感一致 | 每个镜头各弹各的 |

**自查**：每个主要动作单独 0.5 倍速看一遍，看曲线、分量、停得稳不稳（`render.py --video --from --to` 渲那一段，再用 ffmpeg `setpts=2*PTS` 放慢）。

## 动作原则（迪士尼十二条里最常用的七条，加 MG 的两条）

预备动作 · 慢进慢出 · 跟随和重叠 · 弧线 · 次要动作 · 时间和间距 · 夸张 · 错开 · 冲过头再回来（只给真的落地）

## 曲线和时间线：GSAP（业内标准，v4 接入）

动作不再手写缓动，用 GSAP（`引擎/第三方/gsap/`，Standard "No Charge" License，可商用）：几十种打磨过的曲线、自定义曲线、时间线。都是"按时间直接算"：跳到任意 t 都一样。

```js
动.缓('power3.out')(p)                              // 0–1 的曲线：power1–4、sine、expo、circ、back.out(1.6)、elastic.out(1, .5)、bounce.out……
动.补(lt, t0, 时长, 从, 到, 'back.out(1.7)')          // 一个值（数或数组）从 从 补间到 到
const 纸 = 动.时间线('纸飘', (tl, o) => {             // 几段动作排成一条时间线（只建一次），每帧 seek 到 lt 读值
  Object.assign(o, { x: .55, y: 1.8, 转: 0 });
  tl.to(o, { x: .05, y: .55, duration: 1.9, ease: 'sine.out' }, 0).to(o, { 转: 3.1, duration: .8, ease: 'power1.out' }, 2.7); });
const p = 纸(lt);                                   // p.x、p.y、p.转
CustomEase.create('落定', 'M0,0 C.2,0 .1,1.1 .4,1 .6,.98 1,1');   // 自定义曲线，之后 动.缓('落定')
```

怎么选曲线：出现、停稳用 `power2.out`–`power3.out`；离开、加速用 `power2.in`；来回、慢进慢出用 `sine.inOut`、`power2.inOut`；要冲过头一点用 `back.out(1.4–1.8)`；真的弹（长出来、落地）用 `elastic.out(1, .5)`、`bounce.out`；匀速只给漂和持续的运动。运动规范（`运动.js`）的 `曲线` 也可以直接写 GSAP 的名字；2D 摄像机的 `曲线:` 也认。

## 动作库

镜头里一行调用，t 是镜头内的秒数：

| 预设 | 用来 | 写法 |
|---|---|---|
| 到场 / 退场 | 东西出现（快到、慢慢停稳，不冲过头）/ 离开（慢起、加速走掉） | `动.到场(lt, 1.2, { 距离: 40, 角度: 90 })` → `{ a, dx, dy }` |
| 移动 | 从一处到另一处；`预备` 先往反方向收 2–4% | `动.移动(lt, 1, .8, [x0, y0], [x1, y1], { 预备: .03 })` → `[x, y]` |
| 强调 | 轻轻放大再回来，不弹 | `动.强调(lt, 2)` → 缩放 |
| 揭示、变形 | 0–1 的进度 | `动.揭示(lt, 1, .8)` |
| 落地 | 掉下来、着地压扁、余震收住 | `动.落地(lt, 1, .5, 300, { 名: '木箱' })` → `{ dy, sx, sy }` |
| **跳**（v4） | 蹲（前 18%）→ 腾空走弧线、身子拉长 → 落地一沉（后 18%） | `动.跳(lt, t0, .62, [x0, y0], [x1, y1], { 高: 40 })` → `{ x, y, sx, sy, 落 }` |
| 姿势 | 人物换姿势：头先动、手脚晚到晚停，可带预备，不冲过头 | `动.姿势(lt, 2.2, .5, 看光, 回头, { 预备: .03 })` |
| 错开 / 跟随 | 一组东西第 i 个晚多少秒 / 附属部分在主动作 65% 时才跟上 | `动.错开(i)` / `动.跟随(f, lt, 主动作时长)` |
| 淡 / 呼吸 | 淡入淡出用平稳曲线 / 主体待着时的轻微起伏 | `动.淡(lt, t0, .4, true)` / `动.呼吸(lt)` |
| 弹出、长出来 | 冲过头再回落（台阶从地里升起、卡片弹出、东西长高） | `动.补(lt, t0, .55, 0, 1, 'elastic.out(1, .55)')`，或 `MG.pop(lt, t0)` |
| 惯性、晃动 | 停下后的余势、持续的小晃 | `MG.inertia(...)`、`MG.wiggle(t, 频率, 幅度, 种子)` |

3D 里一样用：动作预设算出位置和缩放，再赋给物体（`动.跳` 的 y 是画面坐标往下为正，3D 里取反）。落地的声音对在落地那一刻（`动.跳` 是 t0 + 0.82 × 时长）。

**规矩**：冲过头只给真的落地，字永远不冲过头；预备动作少用（往反方向收 2–4%，0.1–0.17 秒）；任何地方停超过约 2 秒，加漂或小动作。

## 人物动作怎么选

3D 绑骨人物（`S3.人物`，`参考/3D.md`）的身体动作有两个来源：

- **动作捕捉**：身体重心明显移动的动作，站起、坐下、走、推、摔。这类重量感手算很难算对，是真人录的才自然。
- **`动.姿势` 或手写姿势函数**：抬头、转头、手上的小动作。这些不涉及重心，手写更好对准镜头和音乐。

先查库，库里没有才去下载（`脚本/blender/说明.md`）：

```bash
python 脚本/动作库.py 列表
python 脚本/动作库.py 取 站起 <片子目录>
```

```js
await 人.载动作('站起');                                  // 布景里
人.摆(人.捕('站起', { 起: 0, 速: 1 }), lt);               // 镜头里
```

`人.捕` 的选项：`起` 从动作的第几秒开始；`速` 快慢；`循环` 走路这类循环动作，身体继续往前走；`就地` 去掉水平位移；`偏(盆高, t)` 返回 `[x, y, z]` 挪身体；`脚偏` 挪脚 `[x, z]`；`抬头` 把头和颈往上抬。

几个动作连着做用 `人.串`：每段的选项和 `人.捕` 一样，再加 `时长`；后一段的水平位置接上前一段，交接的 `过渡` 秒里两段混合。朝向按数据本身，不自动对齐。

```js
人.摆(人.串([{ 名: '站起', 起: .5, 时长: 2.4 }, { 名: '低头走', 循环: true, 时长: 4.2 }, { 名: '向后摔' }], { 过渡: .4 }), lt);
```

判断标准：

1. **选动作看预览，不看名字。** 看手臂摆不摆、重心对不对。名字普通的动作也可能是持械或带情绪的走法，手臂一直举着。
2. **动作本身要带情绪。** 同样是走，低头走已经在表达状态；先选对情绪，再调快慢，比普通动作加手写修饰省事也更真。
3. **角色比例会放大动作。** 数据是真人比例，头大身短的人物低头、前倾都显得更重，脸也被遮住；用 `抬头` 修正到看得见脸。
4. **衣服会遮住看懂动作靠的部位。** 长外套盖住腿后，蹲着用力可能像跪着滑。样张阶段就用卡里最重的动作试跑，看遮住后还认不认得出来；认不出就换动作或改造型。
5. **和场景的接触要自己对。** 坐椅子时用 `脚偏`、`偏` 让脚踩在椅子前、站起后重心回到脚上；数据里的位移按人物比例缩放，摔、推要留够地方，机位不要穿墙。
6. **看背景。** 人物一动，头可能正好挡住灯、脸前冒出亮光；移动人物或机位，不靠调亮度救。
7. **验收两遍。** 抽帧查穿插和接触；原速的手感机器和抽帧都判断不了，要请用户看。

## 运动规范（每种画风一份）

`片子/<片名>/画风/<画风名>/运动.js`：

```js
STYLES.暗场.运动 = {
  曲线: { 到场: [.2, .9, .3, 1] },   // 只写要改的；默认：到场 [.16,1,.3,1]、退场 [.55,.055,.675,.19]、碰撞 [.55,0,.9,.55]、平稳 [.37,0,.63,1]、揭示 [.65,0,.35,1]
  快慢: 1.2,                          // 所有默认时长的倍数
  每秒张数: 30,                       // 12 或 15 就是一顿一顿的画风；字幕照常平滑
  摄像机效果: ['视差', '惯性', '焦点'],
};
```

几种画风都写了运动规范时，每个镜头写 `画风: '名'`。画风的参数（线宽、圆角、笔触粗细……）写在 `参数.js`，挂在 `STYLES.<画风名>.参数`，镜头从这里取值，不另写数。主体的常用动作（呼吸、待机、转头、抬手）存在画风里，用上面的预设拼。
