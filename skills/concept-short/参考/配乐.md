# 参考：配乐

配乐固定用「若如初见」（`音乐/`：原速、0.9 倍速、0.8 倍速），音乐地图见 `步骤/0_音乐地图.md`。处理写在 `片子.json`，渲视频时自动做好、配上（`脚本/配乐.py`），结论写进 `草稿/检查.txt`。单独试：`python 配乐.py <片子>`。

```json
"配乐速度": 0.9,
"配乐": {
  "剪": [{ "删": [60.4, 67.87] }],
  "压低": [{ "从": 41.0, "到": 43.5, "降": 12 }]
}
```

- **配乐速度**：第 1 步按全片的情绪和快慢选一版。选了慢速版，音乐地图上的时间都除以速度。
- **开头**：从第 0 秒放，0.05 秒极短淡入，只防爆音。
- **剪音乐对准最重的一刻**：差 2 秒以内挪画面；差得多，在重拍点之前删一句或重复一句（一句 4 小节，原速约 7.5 秒），检查会算好删几句、剩下差多少。时间写原速时间，两头在乐句边界上（不在算硬伤），接口交叉淡化 40 毫秒。剪了就在交片时告诉用户剪在哪、为什么。
- **留白**：关键句之前、最重的一刻前后，让音乐退下去（`压低`，片子时间）；降 30 分贝以上就是停下。降 0.3 秒，回 0.5 秒；节拍不错位。
- **结尾**：片尾落在最近的强拍上收住，余音 0.75 秒淡完，不拖长淡出（观众听到音乐慢慢变小就会提前划走）。
- **换算好的地图**：每次做配乐写一份 `草稿/配乐地图.json`（节拍、强拍、乐句、换段、重拍点、响度曲线都换成片子时间），卡拍读它。
- **响度**：整片 -14 LUFS，峰值不超过 -1 dBTP。音效和配乐一起混（`参考/音效.md`）。

## 卡拍

切点和音乐的关系由这一拍决定（`参考/镜头.md`）：卡在拍上有力，画面比拍点早一帧更跟手；错开更松弛；一直卡拍像节拍器。全片最重的一刻对重拍点（画面卡标 `｜最重` 的那张）。

## 检查

| 查什么 | 标准 | 档 |
|---|---|---|
| 剪点 | 两头在乐句边界上 | 硬伤 |
| 片长 | 片子比剪辑后的配乐长 | 硬伤 |
| 峰值 | 不超过 -1 dBTP | 硬伤 |
| 切点卡拍 | 离强拍超过 2 帧的切点（故意错拍的不用管） | 提醒 |
| 最重的一刻 | 离重拍点多远，给出挪画面或剪音乐的方案 | 提醒 |
