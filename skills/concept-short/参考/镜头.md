# 参考：镜头语言和摄像机

2D 镜头的摄像机在 `引擎/camera.js`，3D 镜头的在 `引擎/3d.js`（`S3.机`，见 `参考/3D.md`）。

## 目标

这一页只立目标。怎么做由这一拍决定，下面的手法和工具都是可选的菜单，不是规矩，也可以自创。

**运镜**

1. **看得清**：观众始终知道该看哪里，字读得完，主体看得懂。
2. **有理由**：镜头的每次动或不动，都服务这一拍的意思和情绪。
3. **有分量**：像真摄影机在拍，不像游戏视角在飘。
4. **有变化**：整条片有起伏，不一直是同一种看法。

**转场**

1. **不迷路**：切过去后，观众马上知道人在哪、发生了什么。
2. **不断气**：情绪和动作接得上，该藏的切点藏住，该重的切得有力。
3. **从内容里长出来**：接法替这个转折说话，不为炫技，也不靠滤镜效果撑场面。
4. **有节奏**：整条片的接法有松有紧，切点和音乐的关系由这一拍决定。

判断办法：按真速、像第一次看的人那样看一遍，对照这两组目标。手感抽帧看不出来，要请用户看。

## 对标片的样子（仅供校准）

量过一条优秀的横屏短片：3D 镜头匀速慢推，每秒约 1.4%；中段几乎全是固定机位，动的是画面里的东西；大幅运镜多出现在揭示场景。v4 早期推拉最快到每秒 −13%，还带环绕和手持晃动，看着像游戏镜头，这是"有分量"要防的。这只是一条片的样子，不是标准。

## 手法举例（不是完整清单）

| 手法 | 怎么接 |
|---|---|
| 硬切 | 直接切 |
| 镜内硬切 | 同一场景突然换机位，不压暗，常切在动作上：`CAM.切` / `S3.机切` |
| 动中切 | 动作做到一半时切，下一镜接着把动作做完，切点被动作掩盖 |
| 切镜接着动 | 上一镜结束时摄像机还在动，下一镜带着同样的速度起步 |
| 压暗转场 | 上一镜整体压暗，下一镜从暗里浮出来 |
| 同物变形 | 上一镜的某样东西，变成下一镜的另一样东西 |
| 声音先进 | 下一镜的声音先响起来，画面再切过去 |
| 镜头一路走 | 不切，镜头连续移动、拉远或推近，进入下一个画面 |

## 转场工具（可选）

要画面效果时，给这一镜写 `转场`，以这一镜结尾的切点为中心，前后各占一半；2D、3D 镜头都能用，质感和字幕在混合之后才画，字不跟着变。

```js
SHOT('A2', { 转场: { 名: '压暗', 时长: .9 }, 三维: ... });
SHOT.转场('A2', { 名: '烟', 时长: 1, 参数: { color: 'vec4(.13, .1, .09, 1.)' } });   // 镜头是函数生成的时候这样写
```

现成的有 191 种，来自 gl-transitions，全部存在本地，不用下载，分组和效果见 `引擎/第三方/gl-transitions/目录.md`。`名` 写中文别名（如 `过曝`、`墨`、`撕纸`）或文件名；`参数` 写 GLSL 的值。转场期间前一镜停在最后一帧，后一镜停在第一帧，时长别拖太长；检查可能把转场报成画面跳变，看过没问题就留着。

## 3D 运镜（v4：three-story-controls 的相机支架 + Blender 的相机路径）

3D 镜头的相机挂在纽约时报开源的 three-story-controls 支架上（`引擎/第三方/three/addons/`，Apache-2.0），运镜动作都是摄影术语。每帧先把支架复位到基础机位，再执行这一刻各个动作该走到的量，跳到任意 t 都一样。

```js
S3.运镜(lt, { 位置: V3(-.05, .72, 3.1), 看向: V3(-.1, .36, 0), 视角: 34 }, [{ 漂: .008 }], { 时长: x.d, 光圈: .35 });   // 稳住 + 漂
S3.运镜(lt, 基, [{ 推: .3, 曲线: 'sine.inOut' }], { 时长: x.d });                                                       // 慢推
S3.运镜(lt, 基, [{ 俯仰: 21, 从: .15, 到: 3.4 }, { 摇: -6, 从: .15, 到: 3.4 }], { 视角: 62 });                          // 贴地仰拍，往上仰、往右摇
S3.播相机('塔升', lt, { 看向, 光圈 });   // Blender 里打的路径：布景里 await S3.相机动画('塔升', FILM_URL + '代码/相机/塔升.glb')
```

| 动作 | 是什么 | 单位 |
|---|---|---|
| 推 / 拉 | 推轨（dolly），沿视线前后 | 米 |
| 横移 | 横移（truck），往右为正 | 米 |
| 升降 | 升降（pedestal），往上为正 | 米 |
| 摇 | 摇（pan），往左为正 | 度 |
| 俯仰 | 俯仰（tilt），往上为正 | 度 |
| 滚 | 滚转（roll） | 度 |
| 变焦 | 视角从基础视角变到这个 | 度 |
| 环绕 | 绕 `心`（默认看向点）转，往右为正 | 度 |
| 漂 | 匀速往前推，静止镜头也活着（.01 = 每秒推近 1% 的距离） | 比例 |

每个动作写 `从`、`到`（镜头内秒，不写 `到` 就走到这一镜结束）和 `曲线`（GSAP 的名字，默认 `power2.inOut`）。呼吸（极轻的手持感）、冲击、景深在最后统一加。

**大运镜在 Blender 里打**（摇臂、拉远升起、绕场）：写关键帧清单 `代码/相机/<名>.json`（三维坐标、看向、视角），`blender -b -P 脚本/blender/相机.py -- <名>.json <名>.glb` 导出，贝塞尔曲线自动缓入缓出，要精调就在 Blender 的曲线编辑器里拖手柄。业内调运镜手感就是这么做的。

## 2D 摄像机（camera.js）

画面按远、中、近三层准备，每层一个景深系数：**远 0.3、中（对焦）1.0、近 1.6**，摄像机一动近的移得多、远的移得少。

```js
SHOT('B2', {
  机: CAM({ 推: 1.3, 从: .5, 到: 3.5 }, { 漂: .01 }),
  final: (c, lt, x) => CAM.画(c, x, [[.3, 远景, { 范围: [-300, -300, 2220, 1380] }], [1, 主体], [1.6, 前景]]),
});
// 镜内硬切：每段一台摄像机，段里的 从/到 从段头算
SHOT('B3', { 机: CAM.切([0, CAM({ 漂: .01 })], [2.4, CAM({ 推: 1.2, 向: [900, 600], 曲线: '匀速' })]), final: ... });
```

| 运动 | 写法 | 常见用途 | 常见幅度和时长 |
|---|---|---|---|
| 漂 | `{ 漂: .01 }`，每秒放大 1% | 稳住时不让画面僵 | 每秒 1–2% |
| 推 | `{ 推: 1.3 }`，`向: [x, y]` 同时把那一点带到中心 | 强调 | 1.1–1.5 倍，1–3 秒 |
| 猛推 | `{ 推: 1.6, 猛: true }` | 全片最重的一刻 | 1.5 倍以上，0.5–1 秒 |
| 拉 | `{ 拉: 1.3 }` | 揭示环境 | 同推 |
| 横移 / 升降 | `{ 横移: 300 }` / `{ 升降: 200 }` | 跟着走、揭示上下 | 2–4 秒 |
| 震 | `{ 震: 8, 在: 2.1 }` | 冲击、落地 | 6–10 像素 |
| 呼吸 | `{ 呼吸: 2 }` | 有手持感的画风才用 | 1–3 像素 |

- `从`、`到` 是镜头内的秒数；几个运动可以叠加；曲线默认起步加速、到位刹车，`曲线: '匀速'|'加速'|'刹车'`。
- 首尾相接的两个运动，后一个自动提前 0.3 秒起步。"切镜接着动"：上一镜 `曲线: '加速'` 出去，这一镜 `接上一镜: true`、`曲线: '刹车'` 进来。
- 最远的那层要比画面大（`范围`），镜头怎么走都盖满；字幕不受摄像机影响。
- **拖影**：`CAM({ 拖影: true }, ...)`，快门 180°，快动时沿运动方向叠影子。**移焦**：层的选项 `虚: lt => 0–1`，清楚的和虚化好的两张交叉淡化。

## 检查

| 查什么 | 标准 | 档 |
|---|---|---|
| 露边 | 最远的层没盖满画面；中、近层贴边有实色的那条边被移进画面 | 硬伤 |
| 读字时移动 | 正在读的画里的字每帧移动超过 6 像素 | 硬伤 |
| 太快没拖影、推得太猛、动得太小 | 见 `草稿/检查.txt` 的说明；只作参考，有理由就不用改 | 提醒 |
| 接上一镜 | 切点两边速度对不上 | 提醒 |
