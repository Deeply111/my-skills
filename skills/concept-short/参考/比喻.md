# 参考：比喻从场景里长出来

规矩 9。出自《傲慢》v6：v5 只有三处比喻，其余镜头是"人站着，字幕在讲"；对标的比喻都从场景里长出来——人身上伸出一根线变成手臂，光圈变成别的东西，纸卡变成另一样东西。

## 规则

每张画面卡要有一个比喻元素**把这句话演出来**，而且它是从场景里**已有的东西**长出来的，不是另外贴上去的。画面卡写一行：

```
比喻：<元素> 从 <场景里的什么> 长出来
```

## 四种长法（提示，不限于这四种）

| 长法 | 例子（《傲慢》） | 用什么做 |
|---|---|---|
| 人身上长出线 | 台下的人一开口，一根白线（话线）从兜帽里升起、碰到门槛线就碎成灰；他身上伸出一根白线（手臂）去盖章 | `MG.长线`、`MG.碎灰` |
| 光变成意思 | 光落到他身上，脚下长出台座（"排在最前面"）；胸前的光团（自己有的东西）暗下去；脚下的光圈铺成镜子，镜子里照不出金冠（"不觉得自己傲慢"） | `MG.光团`、3D 的 `S3.光`、`S3.镜面({ 藏 })` |
| 地面和人群变形 | 台阶本来没有，他每次要起跳才从地里升起（"总在找一级更高的台阶"）；俯拍里台下的人变暗、缩小（"下面的人就越小"） | 3D 物体的缩放 + `MG.spring` |
| 道具变成另一样道具 | "比较"纸卡分成两半落进天平两个秤盘；"我是对的"纸卡平躺下来变成新的一级台阶 | 2D 的 `MG.morph`、3D 的倒角盒 |

再加一条前后呼应：最后一个比喻接回全片的主线比喻（《傲慢》的台阶），观众会觉得"原来是这样"。

## 统一视觉语言

全片的比喻元素用**一种颜色或线型**（《傲慢》是金色和白色细线），写进风格卡。观众一眼分清"这是比喻，不是布景"。比喻线、光团画在 2D 层，用 `S3.投影` 贴着 3D 里的东西走。

## 工具（`引擎/lib/mg.js`）

```js
// 长线：从 起 长到 终 的细线（二次曲线，控 是控制点）；进度 0–1 长到哪，尾 0–1 尾巴收到哪；带柔光，尖 画线头亮点
const tip = MG.长线(c, [x0, y0], [cx, cy], [x1, y1], 进度, '#ece7dc', { 粗: 2, 尾: 0, 尖: 2, 透明: 1, 虚线: null });
MG.碎灰(c, [x, y], 进度, '#ece7dc', { 粒: 40, 散: 70, 落: 90, 种子: 1 });   // 一点上的东西碎成细粒，散开、下落、淡掉
MG.光团(c, [x, y], 半径, 亮度, '#eec070');                                 // 中心偏白、外圈是色、柔边的一团小光
```

## 写卡、冷读、审片时问

- 这一句的比喻看得出来吗？是从场景里长出来的，还是贴上去的？
- 比喻的那一刻，镜头给它时间了吗（推近、留白、字幕晚一点出）？小的细节（镜子里没有冠）要推近、给时间，本体上的对照物要亮。
- 有没有两张卡用同一个比喻再讲一遍？
