# 参考：画风模板

skill 的 `画风/` 是画风模板目录，只放用户点头确认收进来的模板（规矩 8）；现在是空的（水墨雾光 v1.1 是 v3 时代的，2026-10-30 按用户的意思废弃，挪到 skill 外面的 `废弃/水墨雾光/`，不再用）。

## 用模板

整个复制到这条片的 `画风/` 再改，连同参数、`格调.json` 和 `样片/`，不直接改模板，在 `片子.json` 记 `"模板": "<名>@v<版本>"`；还要按这条片重新判断合不合适。模板只固定画风，**世界和比喻从这条片重新想**：选最方便表达这条片内容、最契合它的调性和目标的那个世界。样张跑 `脚本/自查.py 格调 <样张> --规格 格调.json`，再和模板的 `标准帧/` 用 `拼图.py` 拼一张对照，不比标准帧差才算过。

## 模板里有什么

模板固定的是画风和格调，不固定世界、比喻和具体画面。能写成代码的写成代码；代码写不了、但能量的做成检查；量不了的用标准帧对照；连图都说不清的才写文字。外来的参考图不放。

```
画风/<画风名>/
  画笔.js  运动.js  主体.js  物件.js   代码：只留画法，去掉片子专有的比喻物件和具体画面
  三维/  模型/                          3D 画风：布景工具和主体模型（同样去掉片子专有的）
  参数.js      线宽、圆角、缓动、每秒张数，几套按情绪分的色板；镜头只从这里取值
  格调.json    能量的门槛（模板/格调.json），自查.py 格调 读它
  样片/        最小的片子目录：片子.json 和 4 张标准帧的镜头代码（远、中、近、最难）
  标准帧/      用 render.py --stills 从 样片/ 渲出来，模板一改就重渲
  风格卡.md    模板/风格卡.md：出处、不变的、可变的、不要、适合和不适合、版本
```

## 收模板（用户点头以后）

1. 把这条片的 `画风/<画风名>/` 复制过来，去掉片子专有的内容，主体只留造型和常用动作。
2. 从这条片拍板过的画面跑 `自查.py 格调`（不带规格）量数，放一点余量写进 `格调.json`。
3. 写 `样片/`，渲 `标准帧/`；写 `风格卡.md`，定 v1。

**升版本**：某条片做出了超过标准帧的东西，先只留在那条片里；回流时列出来问用户，点头才升进模板，重渲标准帧、升版本号、记 CHANGELOG。旧片不跟着重渲。

**复查**：每用五到十条片看一次：腻没腻、哪些规则一直被破、哪些格调门槛从来没拦住过什么，该改的列方案问用户。
