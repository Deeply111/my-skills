# 参考：成片质感

代码在 `引擎/finish.js`。全片一套，写在 `代码/质感.js`，所有镜头做完后统一过一道（业内的合成和调色那一步）。顺序：镜头（3D → 2D 叠加）→ 质感 → 字幕 → 镜头标注，**质感不盖到字上**。

```js
QUALITY({ 溢色: .75, 薄雾: .16, 色散: 1, 畸变: 1, 片门: 1, 分离色调: 1, 抬黑: .022, 高光肩: 1,   // 胶片（《傲慢》的一套）
          颗粒: 1.5, 暗角: .3, 光晕: 0, 纸纹: 0, 雾: null, 调色: { 冷暖: 0, 反差: 0, 饱和: -.2 } });
```

## 参数

| 参数 | 作用 | 参考值 |
|---|---|---|
| 抖动 | 每个像素一层固定的 ±1 色阶细噪，渐变压缩后不出色带；默认开（`抖动: false` 关） | 开 |
| 颗粒 | 只加在平滑的渐变里，每帧变化 | 1–2 |
| 暗角 | 四角压暗 | .2–.3 |
| 光晕 | 只让亮处发光（压暗、拉高反差、模糊，滤色叠回） | .2 |
| 纸纹 | 纸的纹理正片叠底（纸上的画风） | .12–.15 |
| 雾 | 一条横向的雾带 `{ 色, 浓, 从, 到 }` | — |
| 调色 | 冷暖、反差、饱和 −1–1，微调；色彩的定调不能被调歪 | — |
| **溢色**（v4） | 亮处往外渗一圈暖色（胶片乳剂层的 halation） | .75 |
| **薄雾** | 亮处把周围大范围抬一点，空气感 | .16 |
| **色散** | 越靠边红蓝错开越多 | 1 |
| **畸变** | 轻微桶形畸变（先放大一点，四边不露底） | 1 |
| **片门** | 画面极轻的抖动，像片子过片门 | 1 |
| **分离色调** | 暗部偏青、亮部偏暖 | 1 |
| **查找表**、**查找表强度** | 套一张 .cube 调色表（`素材/查找表/`：暖胶片、冷胶片、褪色、银盐、中性；`脚本/查找表.py` 生成，可加）。和分离色调一起用时把分离色调降到 .3–.5，免得叠两层；每镜可改强度、不能换表 | 不开 |
| **抬黑** | 黑不死，蒙一层灰 | .022 |
| **高光肩** | 亮处柔和地收，不刺眼 | 1 |
| **漏光** | 右侧渗进一道暖光（按镜头开，开头、结尾、转暖时） | 0–.6 |
| **闪白** | 整幅冲白（转场、揭晓的一下） | 0–1 |

胶片这一组默认都是 0；开了任何一样，就先用显卡（WebGL）过一遍再做上面那些，2D 片也能用。按画风选，做到"去掉了才发现少了什么"；手持晃动、畸变这类只是"显得专业"、不服务五条目的的，宁可不开（取舍标准）。

## 按镜头微调

```js
SHOT('A1', { 质感: { 溢色: .9, 薄雾: .22 }, ... })                                         // 侧脸、标题光晕重一点
SHOT('K1', { 质感: lt => ({ 漏光: .5 * Math.sin(Math.PI * Math.min(1, lt / 1.6)) }), ... })   // 结尾转暖时漏一道光
```

和全片的合并，只这一镜生效。

## 检查

| 查什么 | 标准 | 档 |
|---|---|---|
| 色带 | 关了抖动时，有渐变首尾只差不到 30 个色阶 | 提醒 |
| 画面自己在抖 | 同一帧画两次不一样（质感里用了上一帧的东西也会这样，v4 修过两处：模糊用的小画布要先清空） | 硬伤 |
