# 转场目录

来自 [gl-transitions](https://github.com/gl-transitions/gl-transitions) 2.5.0，共 191 种，全部已存在本目录，渲染时读本地文件，不用联网；用哪个才读哪个，没用到的不影响渲染。

用法：`转场: { 名: '过曝', 时长: .9 }`，`名` 写中文别名（表里加粗的）或英文文件名都行。这里只是菜单，分组只是方便找，怎么选看 `参考/镜头.md` 的目标。

调参数：每个 `.glsl` 开头的 `uniform ...` 就是可调项，写进 `参数`，值按 GLSL 写，如 `参数: { color: 'vec4(.13, .1, .09, 1.)' }`。

191 种都试过：能编译；除了表里注明的，开头和结尾都和前后两镜对得上，不会跳。效果只抽帧看过，真速手感要看成片。没有收 `DisplacementMap` 和 `LumaWipe`，它们要额外的贴图，工具不支持。
