# Blender 脚本

3D 画风的人物和主要物件在第 2 步（样张）建好模、烘好阴影，放进 `片子/<片名>/画风/<画风名>/模型/`，布景里用 `await S3.模型('/film/画风/<画风名>/模型/<名>.obj')` 读。

## 装 Blender

便携版，放在 `~/blender/blender-4.2.3-windows-x64/`（没装进系统，约 640MB），命令行全程无界面跑（`-b`）。放别处时设环境变量 `BLENDER`（`脚本/动作库.py` 用）。

换了机器没有的话：从 https://download.blender.org/release/Blender4.2/ 下 `blender-4.2.3-windows-x64.zip`（约 380MB），解压到 `~/blender/`，不用登录、不用接受协议。不要放会话的临时目录，换会话就没了。

## 脚本

| 脚本 | 做什么 | 怎么跑 |
|---|---|---|
| `人形.py` | 兜帽人模板（《傲慢》）：袍、披肩、带真开口的兜帽、可选的冠；建完直接烘阴影、导出 OBJ | `blender -b -P 人形.py -- <输出.obj>`；先复制到片子的画风里，按这条片的主体改身形和褶 |
| `绑骨人.py` | 能动的人物模板：一个人偶，骨架、骨名、权重和引擎 `S3.人物` 对好，导出 `.glb` | 复制到片子的 `画风/<名>/模型/`，改「身体」一段；`blender -b -P 绑骨人.py -- <输出.glb>` |
| `取动作.py` | 把 Mixamo 的 FBX 转成每帧骨骼数据 | 由 `脚本/动作库.py 入库` 调用，不用手跑 |
| `烘焙.py` | 任何模型（OBJ 或 .blend）的环境光遮蔽烘进顶点色，导出 OBJ | `blender -b -P 烘焙.py -- <输入> <输出.obj> [采样数]` |
| `模拟.py` | 刚体（倒塌、掉落、散开）和布料、软体的模拟一帧帧算完，烘成 `.json`（刚体每帧的位置和旋转）+ `.bin`（布料每帧的顶点），给 `S3.回放` | `blender -b 场景.blend -P 模拟.py -- <输出.json> [起帧 止帧]`；或在片子的建场景脚本最后 `import 模拟; 模拟.烘焙(输出, 起, 止)` |
| `相机.py` | 按关键帧清单（three.js 坐标、看向、视角）打相机动画，贝塞尔曲线缓入缓出，导出 .glb 给 `S3.相机动画` | `blender -b -P 相机.py -- <关键帧.json> <输出.glb>` |

## 从 Mixamo 取动作

先查库：`python 脚本/动作库.py 列表`。库里没有才下载：

1. 用内置浏览器打开 mixamo.com。登录状态会保留；要登录或接受条款时，由用户自己操作，不代填账号密码。
2. 不上传人物，只下动作：顶部 Animations 里搜，**看预览确认动作**（手臂和重心，`参考/动作.md`），再点 Download。
3. 下载设置：Format 选 FBX Binary，Skin 选 Without Skin，Frames per Second 选 30，Keyframe Reduction 选 none。不勾 In Place，水平位移由 `人.捕` 的 `就地` 决定。
4. 内置浏览器不会把文件存到硬盘：下载后读页面对 `/api/v1/characters/<id>/monitor` 请求的响应，`job_result` 是临时下载链接（5 分钟内有效），用 curl 存下来。每次下载前要有用户的同意（动作名、来源、大小）。
5. 入库：`python 脚本/动作库.py 入库 <fbx> <名> --mixamo "动作名" --说明 "页面上的描述" --注意 "用的时候要注意什么"`。

## 注意

- **装好以后先跑一遍 `相机.py` 试导出**：这台机器第一次装的 Blender 少解压了近 5000 个文件，glTF 导出插件因此报 ImportError（`gltf2_blender_gather_primitive_attributes`）；重新下载压缩包、把缺的文件补齐才好。缺文件时 OBJ 导出照常，只有 glTF 坏。

- 虚拟机上 Blender 的 EEVEE 可能跑不了（VMware 虚拟显卡的存储缓冲上限是 8，EEVEE 要 9–10 个）。不管在哪台机器，**Blender 只用来建模、烘焙和打相机路径**，片子在浏览器里用 three.js 渲（`引擎/3d.js`）。
- 模拟：刚体的物体要先把缩放烘进网格（`transform_apply(location=False, rotation=False, scale=True)`，默认三样都烘，位置也会被烘掉）；地面设成 PASSIVE 刚体，布料要碰的东西加 Collision 修改器。帧率统一 30。实测 14 个刚体 + 625 点的布料 60 帧，烘焙 4 秒。
- 导出的 OBJ 是 Y 朝上、+Z 朝前（three.js 的约定）。模型高 1.0，在 three.js 里按画风缩放。
- 顶点色里存的是阴影（0–1），`S3.模型` 读进来时按 5%、97% 分位拉开对比，材质要开 `vertexColors: true` 才会乘上去。
