# 第 1 步：画面卡

读文案，逐句写画面卡，排好时间。产出 `片子/<片名>/画面卡.md`（开头是读文案的结果，下面是卡）和 `代码/时间轴.json`。不交给用户，写完做冷读测试。**节奏和切点在这一步就定**（v4 没有动态分镜了）。

## 一、读文案

用户按自己的习惯写，不会加约定好的记号，先读懂每一句是什么。

| 上屏的 | 怎么处理 |
|---|---|
| 字幕 | 说法不改，只切分、断行 |
| 心里话、对白 | 上屏，和旁白在字的样子或位置上区分开 |
| 引用和出处 | 原话和出处照抄，排成引文 |
| 关键字、画面里的字 | 不按字幕放，做成画里的东西 |

不上屏的（画面描述、镜头、声音、节奏、意图、参考）用在卡里。标记翻译成呈现：强调统一写成【】（一句最多一处）；句中的 / 和回车是断行；……、——、空行是停顿；序号、小标题只帮助分段。

**要先问用户的**：备选的说法（括号里另写一种、打了问号），以及分不清是字幕还是描述的句子。读完一起列出来问，一次问完（"直接做"模式下自己定，交片时说明）。

然后写下：
- **一句话主旨**，开头、全片最重的一刻、结尾分别在哪一句。最重的一刻：有揭晓的就是揭晓；没有的，是情绪强度最高的那一刻。
- **按情绪单元分段**：意思或情绪一转弯（但是、所以、其实……）就开一个新单元，就是后面的"场"。
- **每条字幕**：观众明白什么（一句，和上一句不重复）、情绪强度 1–5、要找比喻的抽象词、读法（重读、停顿、是不是心里话）。
- **断行**：每行最多 16 字，最多两行，在标点和词组之间断开。行尾不留句号、逗号、顿号、分号、冒号，句中停顿用空格，问号、叹号留着；这只是排版，不算改说法。

## 二、画面卡开头：全片写一次

**看下去的理由**：开头 2 秒用什么抓住人（一个怪事、一个问题、一个反常的画面）；每场观众在好奇或期待什么、到哪里揭开；全片的起伏。

**主线比喻和母题表**：全片反复出现的几个形象，每个写清代表什么、怎么一步步变化，数量尽量少（《傲慢》：台阶）。最后一个比喻尽量接回主线。

**方位约定**：什么方向代表什么，之后每张卡都守。

**配乐速度**：按情绪和快慢从原速、0.9、0.8 倍速里选一版，写进 `片子.json`（`参考/配乐.md`）。

## 三、场和卡

```
## 场 <编号>　<场名>　（约 <起>–<止> 秒｜音乐：<段落强弱>）
目的：　　情绪：　　快慢：
环境：<声音素材名或配方名>
新出现的东西：

### <编号>　<字幕>　强度 <1–5>｜难度 <★–★★★>
观众明白：
看懂的那一刻：
看到什么：
比喻：<元素> 从 <场景里的什么> 长出来
3D/2D：空间、光、材质用 3D 的是哪些；字、线、UI 用 2D 的是哪些
表演：（画面里有人时）
构图：
镜头：
动效：
字幕处理：
接下一句：
时长：
```

一句字幕一张卡，一张卡里可以有不止一个镜头；没有字幕、画面自己演的段落也单独写一张（"（无字幕）"）。全片最重的一刻那张卡，标题行末尾加 `｜最重`（只标一张）。

| 项 | 必须写到 |
|---|---|
| 观众明白 | 一句完整的话 |
| 看懂的那一刻 | 画面里具体哪个瞬间 |
| 看到什么 | 谁、在哪、做什么，遮住字幕也懂 |
| **比喻** | 这句话由哪个画面元素演出来、它从场景里已有的什么长出来（规矩 9，`参考/比喻.md`） |
| 3D/2D | 按 `参考/3D.md` 的分工表 |
| 构图 | 主体在哪、占多大，最重要的东西最大、最显眼；字幕放哪（横屏默认下方，主体在下时放上方） |
| 镜头 | 这一拍想让观众得到什么、打算怎么拍（`参考/镜头.md` 的目标） |
| 动效 | 主动作的快慢和分量 |
| 接下一句 | 这个转折想让观众感到什么、打算怎么接（`参考/镜头.md` 的目标） |
| 字幕处理 | 种类和出场（`参考/字幕.md`），普通句也写"普通"；有要砸下去的词就在标题行标【】；字进世界的写"关键字代替"，并写清字在世界里做什么 |
| 时长 | 秒数，加上读字下限 |

选写：光色、声音、关键字、停顿。字幕处理的种类有问句、结论、落点、心里话、引文，出场有浮现、意群、逐字、重读、揭示。

**每场想一次字**：这一场有没有一句话的关键词能变成这个世界里的东西，写卡时就定，不留到做完再补（`参考/字幕.md`"字进世界"）。

**每张卡既要看得懂，也要给一点新东西**：一眼就明白的形象，主次分明，一次不塞太多；和上一张不是同一个意思再讲一遍；这一刻观众在好奇什么。

## 四、节奏和时间

节奏由助手把控。**读字时间只是下限**（字数 ÷ 6 + 出场 + 退场，普通 0.5 秒），不决定节奏。决定节奏的是：

- **情绪的起落**：铺垫可以快，转折和结论后面留出时间；高潮之后留呼吸。
- **在观众看懂的那一刻之后切**，稍等一下；切早了没看懂，切晚了就拖。
- **按信息量定时长**：新的、复杂的停久一点，回扣的可以短。
- **快慢要对比**：例子、罗列快切，最重的几处给长镜头；镜头长短不要平均。
- **跟音乐**：切点和音乐的关系由这一拍决定；最重的一刻对重拍点，差 2 秒以内挪画面，差得多剪音乐（`参考/配乐.md`）。安静段适合慢，满的段落推进。
- 冲突时按这个顺序让：情绪 > 故事 > 节奏 > 视线 > 画面关系（默奇）。情绪越紧张，画面对比越强（布洛克）。

写好 `代码/时间轴.json`：每个镜头 `{ "id", "from", "to", "卡" }`。

## 五、冷读测试

画面卡写完后，派一个没参与过的 agent，只给每张卡的"看到什么"（不给字幕和意图），让它逐张写这一镜在说什么，再答四问：哪几处最想看下去，哪几处最想划走，哪两张在讲同一件事，**哪几张的比喻看得出、哪几张看不出或像贴上去的**。和卡上的"观众明白"对照：对不上的、想划走的、重复的、比喻看不出的都要改，改完再测这几张。说某张"全靠字"的，不能用"成片有字幕"跳过：改画面，或者带上字幕再测一次。

**自查**（按第一次看的观众）：开头 2 秒抓不抓人；每一处比喻看不看得出；哪里会划走。
