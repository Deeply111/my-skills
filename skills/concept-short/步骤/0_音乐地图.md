# 准备工作：音乐地图

只做一次，所有片共用。换了配乐、或者发现地图标错了，才重做。

## 做法

```
cd 脚本
uv run --no-project --python 3.12 --with librosa --with matplotlib --with "numba==0.67.*" python music_map.py
```

numba 钉在 0.67：这台机器开着 Windows 智能应用控制，会拦 numba 0.68 的 DLL（报"应用程序控制策略已阻止此文件"）。

只分析 `音乐/原速.mp3`。0.9、0.8 倍速版是整体等比放慢的，任何时间点都等于原速时间除以速度，不用另外分析。

产出都在 `音乐/`：

| 文件 | 是什么 | 谁用 |
|---|---|---|
| `音乐地图.json` | 节拍、强拍、乐句、换段、段落强弱、重拍点、响度和亮度曲线（原速时间） | 第 1 步排时间；之后各步读每条片换算好的 `草稿/配乐地图.json`（`脚本/配乐.py` 按配乐速度和剪辑换算） |
| `波形图.png` | 波形和响度曲线上标出乐句、换段、重拍点 | 验证地图；写画面卡时看全局 |
| `校验.mp3` | 配乐叠咔哒声：强拍高音、普通拍低音、换段处一声钟 | 给人耳复核 |

## 地图里各项怎么用

| 项 | 用在哪 |
|---|---|
| 节拍 | 精修时，冲击点（落地、绷紧、撞上）对准拍点 |
| 强拍 | 想切得有力时可以放在这里 |
| 乐句（4 小节一句） | 换场可以放在乐句的起点上 |
| 换段 | 大的转折、换场景可以放在这里 |
| 段落强弱和走向 | 安静段给要观众想一想的句子；满的段落给推进和高潮；样张色条的明暗跟着它走 |
| 重拍点 | 从不满进入满的那一下，留给全片最重的一刻 |

**画面比拍点早一帧。** 切镜头和冲击点放在拍点前一帧（30 帧下约 33 毫秒，不超过两帧），看起来才是正好踩在拍上：人眼处理画面比耳朵处理声音慢一点，而且观众对"声音晚到"宽容、对"声音抢先"敏感。音效不跟着提前，和画面里碰到的那一帧对齐。

## 怎么验证

- 脚本会打印拍点上和拍间的起音强度比值，大于 1.3 才说明拍子落在起音上。
- 看波形图：换段的红线要落在波形明显变化的地方。
- 机器验不了的，用 `校验.mp3` 听一遍。

## 若如初见（原速）的结构

128 BPM，每小节约 1.875 秒，4 小节一句（约 7.5 秒）。音乐约 151 秒处结束。

| 段落（秒） | 小节 | 强弱 | 说明 |
|---|---|---|---|
| 0–15.4 | 8 | 中 | 前奏 |
| 15.4–45.4 | 16 | 满、亮 | 第一个重拍点在 15.4 |
| 45.4–60.4 | 8 | 安静 | 全曲最安静 |
| 60.4–75.4 | 8 | 中、暗 | 铺垫 |
| 75.4–105.4 | 16 | 满、亮 | 第二个重拍点在 75.4 |
| 105.4–135.4 | 16 | 满、暗 | 一样响，音色变暗变厚 |
| 135.4–结束 | 9 | 中→收 | 尾声 |
