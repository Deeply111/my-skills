# 手绘风口播视频封面

**最重要的一条：每次出图都要传 2 张风格参考图。**
只靠文字描述，模型画不出这种"排线马克笔字 + 白边虚线人物"的感觉；带上参考图，风格才能稳定对上。
参考图默认用 `examples/` 里自带的两张样板，用户也可以换成自己的。

## 动手前

1. 看一眼 `examples/style-A_人左下_流程图.png` 和 `examples/style-B_人右下_截图.png`
2. 读 `references/style-dna.md`（风格规则）

## 输入

| 输入 | 必给 | 没给怎么办 |
|---|---|---|
| 口播稿或这期讲什么 | ✅ | 问用户要 |
| 出镜人物照 | ✅ | 问用户要。要求：正脸清楚、上半身、最好带手势（指向、点赞、摊手都行） |
| 封面标题 | ❌ | 第 1 步帮他出 |
| 参考封面 | ❌ | 第 0 步问一句，没有就用自带样板 |
| 产品截图 | ❌ | 有就放截图，没有就画手绘流程图 |

## 流程

### 0. 开头先问一次（一条消息问完，别分几次问）

> 开始前确认三件事：
> 1. 口播稿或这期讲什么（必给）
> 2. 你的出镜照片（必给，正脸 + 上半身，最好带手势）
> 3. 有没有自己喜欢的手绘风封面想参考？有就传 1～2 张，**没有也没关系，我用自带的样板**

用户传了参考封面：用它替换对应的自带样板（传 1 张就替换 1 张，另一张仍用自带的）。
**提醒用户：参考图只学风格，里面的字和人不会出现在新封面上。**

### 1. 出标题 → 用户选
按 `references/title-extraction.md` 出封面大标题 3 版、小标题 3 版，标出推荐。
**用户选完再往下走。** 文字是唯一不能靠重新出图解决的东西。

### 2. 看人物照
- 衣服主色（定配色用）
- 手势朝哪边（定人物和流程图谁左谁右：手势要指向流程图）
- 照片里要保住的东西：手势、衣服、配饰（领夹麦、眼镜等）

### 3. 设计流程图 → 给用户看一眼
按 `references/prompt-template.md` 末尾「流程图怎么从口播稿里想」，3–4 格，每格 2–5 字，最后一格是结论。
有真实截图时可以放截图代替流程图。

### 4. 选配色和构图
```bash
python3 scripts/pick_palette.py --wardrobe 米白 -n 3
```
`--wardrobe` 填人物衣服颜色（灰、墨绿、藏青、紫、棕、米白……）。从结果里挑一组。
构图：画流程图用 **A**（人左下、流程图在右），放主截图用 **B**（人右下、截图在左）。

### 5. 出 3:4
1. 按 `references/prompt-template.md` 填好提示词，存成 `prompt_3x4.md`
2. 有 Codex 就直接出图：
```bash
python3 scripts/gen_cover.py --ratio 3:4 --prompt prompt_3x4.md \
  --style examples/style-A_人左下_流程图.png --style examples/style-B_人右下_截图.png \
  --person <人物照> [--shot <截图>] --out <工作目录>/<主题>_封面_v1_3x4.png
```
   参考图顺序：**和本期构图相同的那张放第一张**。用户给了参考封面就换成他的。
   一张约 3 分钟，用后台运行，别干等。
3. 看图，按 `references/qa-checklist.md` 自查，不合格就改提示词出 `_v2`
4. 发给用户确认

### 6. 补 4:3 和 16:9
按 `references/layout-recipes.md` 重排（不是裁切），风格参考换成 **本期 3:4 成品 + 1 张同构图样板**。
两张可以同时跑。自查后三张一起给用户。

## 没有 Codex 怎么办

`codex` 命令不存在，或 `codex features list` 里 `image_generation` 不是 true：
```bash
python3 scripts/gen_cover.py --dry-run --ratio 3:4 --prompt prompt_3x4.md \
  --style ... --style ... --person <人物照> --out <输出路径>
```
它会打印**完整提示词 + 要按顺序上传的图片清单**。把这段交给用户，
让他在 ChatGPT（GPT-image）、即梦、Nano Banana 等支持多图参考的生图工具里，**先按顺序传图，再粘贴提示词**。
你自己的环境里如果有别的生图工具，也按同样的附件顺序直接调用。

## 交付

- `<主题>_封面_v<N>_3x4.png` / `_4x3.png` / `_16x9.png`
- 每张对应的提示词文件（下次改字直接改它重跑）
- 一句话说明：用了哪组色、哪个构图、哪两张风格参考

## 边界

- **不改用户选定的文字。**
- **不覆盖旧版本**，每次出新图加版本号（脚本会拒绝覆盖）。
- **一张封面只讲一件事。**
- **不杜撰界面**：用真实截图时不让模型重绘 UI。
- **不改人物**：不美化、不换脸、不改手势和衣服。

## 交付前自查

- [ ] 标题是用户选过的？
- [ ] 流程图给用户看过？
- [ ] 每张都传了 2 张风格参考图？
- [ ] 每张都看过，过了 `qa-checklist.md`（字对不对、白边有没有、脸像不像）？
- [ ] 3:4、4:3、16:9 都出了，横版是重排不是裁剪？
