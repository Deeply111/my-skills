# 出图后自查

每张图生成后**先自己看一遍**（用 Read 打开图片），不合格就重出，别把明显有问题的图推给用户。

## 文字（最常翻车）

- [ ] 每一个中文字都和给定文案**完全一致**，没有错字、漏字、多字
- [ ] 没有多出来的英文乱码，也没有照抄参考图里的字
- [ ] 标题没有被人物、佐证物切掉任何一笔

## 人物

- [ ] 脸像本人，没有被美化、改年龄、卡通化
- [ ] 手势、衣服、配饰和照片一致
- [ ] **有白色贴纸边 + 外圈彩色虚线** —— 白边最容易被漏掉
- [ ] 照片原背景（窗帘、台灯、椅子）全部去掉了

## 风格

- [ ] 标题是排线马克笔字，不是规整印刷体
- [ ] 米白纸底，不是纯白、渐变、深色
- [ ] 三张（3:4 / 4:3 / 16:9）放在一起像同一期

## 颜色

- [ ] 只有 2 个主色（+ 最多 1 个点缀色），没有乱入的颜色
- [ ] POP 色没有压过 INK 色，整张图不刺眼
- [ ] 放射短线 ≤ 2 组，主标题两侧没有"点点"
- [ ] 流程图箭头顺序一眼能读懂（2×2 是 Z 字形、只有 3 个箭头）

## 缩略图测试

把图缩到 200px 宽：
- [ ] 钩子词还认得出来
- [ ] 人脸还认得出来

## 交付

- [ ] 3 张都出了，16:9 和 4:3 是重排不是裁剪
- [ ] 文件名带日期、主题、版本、尺寸：`AI验收员_封面_v1_3x4.png`
- [ ] 没覆盖旧版本

## 重出的判断

| 现象 | 怎么改 |
|---|---|
| 字错了 | 在【文字准确性】里把错的那条单独再强调一次，重出 |
| 没有白边 | 【人物】段加一句"白边是本系列识别符号，必须有" |
| 不像这个风格 | 同构图的样板放第一张；还不像就请用户给一张喜欢的手绘封面当参考 |
| 脸不像 | 换一张更正脸、更清楚的人物照；在附件说明里把"图 3 人物"写在最前面 |
| 太花太吵 | 删掉一半装饰，POP 只留钩子词 + 一条下划线 + 描边 |
| 横版排得像压扁的竖版 | 风格参考用本期 3:4 成品，并在提示词写清"按横版重新排版，不是裁切" |
