# 生图提示词模板

## 为什么一定要带参考图

只给文字描述，模型猜不出"排线马克笔字 + 白边虚线人物 + 手绘流程图"的样子。
所以**每次都传 2 张风格参考图**，文字只负责说清"这期写什么、放哪"。

## 参考图怎么挑

附件顺序固定：**图 1、图 2 = 风格参考，图 3 = 人物照，图 4 = 真实截图（可选）**。

- 默认用 `examples/` 的两张自带样板，**和本期构图相同的那张放图 1**（A 构图放 `style-A`，B 构图放 `style-B`）。
- 用户给了自己喜欢的手绘封面：替换掉图 2（只给 1 张）或两张都替换（给了 2 张）。
- 出横版时：图 1 = 本期 3:4 成品，图 2 = 同构图样板。

自带样板里的人物位置是**灰色剪影占位**，那是为了只教"白边 + 虚线描边"的画法、不带任何真人脸。
提示词里要写明：人物用图 3 的真人，不要画灰色剪影。

## 槽位怎么填

| `{{SHOT_LINE}}` | 有截图：`- 图 4：真实产品截图，内容原样放置，不要重绘或杜撰界面细节。`；没有就删掉这行 |

## 佐证物写法

**① 手绘流程图**（默认）
```
和图 1、图 2 一样的手绘流程图：{{N}} 个手绘圆角方框（{{排列：2×2 / 一排 / 竖排}}），{{INK}} 手绘线框，
每个框里一个扁平小图标（图标下垫一块很浅的低饱和色圆底），图标下方是标签：
「{{1}}」→「{{2}}」→「{{3}}」→「{{4}}」，框之间用黑色小箭头连接。
2×2 排列时写清 Z 字形路线、**只画 3 个箭头**：左上 → 右上，右上斜向 ↙ 左下，左下 → 右下。
（不写的话模型会画成每格都往两边指，读的顺序乱。）
最后一格用 {{POP}} 粗框强调（它是结论）。
```

**② 真实截图**
```
放置图 4 的截图，内容原样，不要重绘或杜撰界面细节。外面套一圈 {{POP}} 手绘虚线边框，略微倾斜，像贴在纸上。
```

**③ 问题 → 解决**
```
左边画一叠乱糟糟的 {{旧东西}}，旁边两个灰色对话气泡「{{吐槽1}}」「{{吐槽2}}」；
{{POP}} 手绘弯箭头指向右边的 {{新结果}}（手绘边框小窗）。
```

## 流程图怎么从口播稿里想

流程图讲的是**这期的论证路径或操作路径**，不是目录：
- 观点类：证据 1 → 证据 2 → 证据 3 → **结论**
- 教程类：输入 → 处理 → 处理 → **产出**
- 每格 2–5 个字，3–4 格，最后一格是钩子。先给用户看一眼再出图。
