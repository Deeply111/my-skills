# 从口播稿出封面标题

**前提**：用户给了标题就直接用，不要改。这份只在他没给时用。

## 产出三样东西

| 产出 | 规格 |
|---|---|
| **封面大标题** | 2 行（最多 3 行），每行 6–12 字，`【】`标出撞色钩子词；给 3 版 |
| **封面小标题** | 12–18 字，有动词或可带走的东西；给 3 版 |
| **第三层小字条**（可选） | 一句短金句，≤ 12 字；用户想加才加 |

## 封面大标题

1. **找出这期唯一的那件事**：观众看完会记住哪一句？一张封面只讲一件事。
2. **选一种钩子**（不要混）：

| 钩子 | 例子 |
|---|---|
| 痛点反问 | AI 的回复总是【又长又复杂？】 / 口播【太干】没人看？ |
| 反常识判断 | 真正浪费你时间的，是你没意识到的【坏习惯】 |
| 认知断言 | 你赚不到【认知以外】的钱 |
| 工具 + 结果 | 这个【免费工具】我每天都在用 |
| 玩法 / 身份 | 口播视频剪辑的【邪修】玩法 |

3. **断行**：钩子词不能被断开；工具名尽量放行首；横版要能合并成 2 行。

## 封面小标题

- 讲清"这期给你什么"，别重复大标题的词。
- 好：「从 0 到第一笔收入的路线图」「一键整理所有笔记」「3 分钟看懂工作台逻辑」
- 差：「关于 AI 的一些思考」

## 交给用户确认

**出完先给用户选**，他定了再往下走。文案是封面里唯一不能靠重出解决的东西。
