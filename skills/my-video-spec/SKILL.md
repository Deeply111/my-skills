# 【规范名称，比如：我的探店短视频】

## 成品

【一两句话：成片长什么样。写清时长、横屏还是竖屏、给谁看、发在哪个平台、文案和配音由谁出。】

## 判断标准

【一句话：什么样算做对了。写最容易做歪的那一点，最好带一个反例，比如「每个画面都为这句话而做；标题加三个要点的翻页 PPT 不算」。】

## 硬性要求

**流程：分几步，每步停下等我点头**（我说「一口气做完」就不停）

1. 【第一步交什么，比如分段规划表，写出表头：段号、起止秒、原句、做法……】
2. 【第二步交什么】
3. 【做画面时每段做完怎么检查，比如用 `npx openfilm look` 看第一帧、关键帧、最后一帧】
4. 【最后的自查：按下面哪几组规则逐条打勾，交表给我】

**节奏**

- 【开头：几秒内画面要动、几秒内出标题或钩子】
- 【密度：大约几秒一个动作；同一种动效最多用几次；转场怎么换】
- 【对齐：画面和配音怎么对上，比如关键词落定帧 = 念到它的那一帧，误差几秒】

**画面**

- 【配色：一段一色，还是全片一套；颜色从哪来（品牌色、段落表）】
- 【文字：最小字号（1080p 下多少像素）、画面上留多少字】
- 【留白：字幕区、平台按钮会挡住的区域不放内容】
- 【开头第 0 帧和结尾怎么处理】

**字幕**（Studio 按配音的 `.vtt` 生成，页面里不画字幕）

- 【样式：Studio 字幕面板里的哪一套（描边、背景条、粗体粗描边、黄色、无描边），大小，离底边多远；逐字高亮用变色、高亮底框还是弹跳，什么颜色；淡入淡出几毫秒】
- 【一行最多几个字；重点词要不要另外在画面里放大】
- 【想每个项目都一样：在 Studio 里调好一次，把那个项目的 `.film/subtitles.json` 复制进这个技能文件夹，再写一句：项目里还没有 `.film/subtitles.json` 时，把技能文件夹里的那份复制过去；已经有了就不动】

**声音**

- 【背景音乐：比人声低多少（比如低 12 dB 左右，约为人声的 1/4）；人声说话时要不要再压低；开头、结尾淡入淡出几秒】
- 【音效：什么时候响（比如每条字幕出现、关键词落定、转场），每分钟最多几次，用哪几个文件】
- 【成片整体多响，比如 −14 LUFS，误差几 dB】

**文案和配音**（交给智能体写或改时才需要）

- 【句子长度、口吻、哪些词不许用】

**不要**

- 【你最受不了的 AI 味，写成具体的样子，比如「深色仪表盘背景」「一屏密密麻麻的小字」「结尾总结三句话」】

## 你手上有什么

- 【素材在哪：配音、实拍、截图放在 `assets/` 下；参考片放在 `references/`，只用来学，不进成片】
- 【你的品牌：logo、颜色、字体文件在哪】
- 【照着一条对标片定的规范：先用官方「复刻」技能（replicate）拆它，把测出来的切点间隔、字幕样式、音效落点填进上面几栏】
- 网页技术和上面的任何动画库；配音、音乐、音效用 `npx openfilm get` 取（先在 Studio 的设置里连好服务）；用 `npx openfilm look` 检查画面。
- 【做不到时怎么办：直接说，给一个降级方案】
