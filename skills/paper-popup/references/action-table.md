# 逐句动作表：怎么写

做法借自 FredTalk 的"逐句动作表"，又吸收了 concept-short（skill-v4）的画面卡：读口播、比喻从场景里长出来、看懂的那一刻、冷读测试。它是每一期的导演稿：先把每句话**画面上发生什么**想清楚，再写代码。写代码时只照表实现；表里做不到的，回来改表，不在代码里临时改方向。

## 一、先读口播（表头写一次）

- **一句话主旨**：这一段要观众带走什么。后面每一行都为它服务。
- **开头 2 秒靠什么停下来**：一个怪事、一个反常的画面、一个问题。口播第一句往往就是钩子，画面要把它变成看得见的。
- **最重的一刻**：有揭晓的就是揭晓；没有就是情绪最高的那句。只标一行（行号后加 `｜最重`），镜头、音效、留白都先给它。
- **情绪单元**：意思一转弯就开一个新单元 = 行号里的 A1、A2……
- **每句的强度 1–5**：铺垫快、低；转折和结论后面留时间。

## 二、贯穿的对象（母题）

哲学心理内容抽象，先把概念换成**看得见、会动的纸片东西**。每个写清代表什么、从哪来、怎么一步步变、到哪去。同一个对象贯穿下去，结尾接回前面的对象，观众会觉得"原来是这样"。

**方位约定**也写一次：什么方向代表什么，之后前后一致。

## 三、比喻从纸上长出来

每一行要有一个比喻元素**把这句话演出来**，而且它是从画面里**已有的东西**长出来的，不是另外贴上去的。纸面立体书天然适合：东西本来就是从纸上翻起来的。

写法：`<元素> 从 <已有的什么> 长出来`。长法有很多：从纸面翻起、印着的变成立着的、对象变形或留下痕迹、一样东西变成另一样、"你"的动作……按这一句想。

问自己：遮住字幕，这一句的比喻看得出吗？那一刻镜头给它时间了吗？有没有两行用同一个比喻再讲一遍？

比喻元素在视觉上有统一的标记（颜色、线型），观众一眼分得清"这是比喻，不是布景"。

## 四、每一行的栏目

| 栏 | 写什么 | 不合格的写法 |
|---|---|---|
| 行 | A段·句，如 A2·3；最重的一行加 `｜最重`。场景代码的注释用同一个编号 | — |
| 口播 | 原话要点 | — |
| 强度 | 1–5 | — |
| 2D/2.5D | 这一句用正俯视的平面（2D），还是立起来的立体书（2.5D），或者在这句里切换 | 不写，全片一个角度 |
| 比喻 | `<元素> 从 <已有的什么> 长出来` | "相关图标"；凭空贴一个新东西 |
| 发生什么变化 | **看得见的状态变化**，按念到的字定时 | 把旁白换个说法；只写组件名 |
| 看懂的那一刻 | 画面里具体哪个瞬间观众明白了；视线落在哪 | "整句" |
| 证据和字 | 重建示意 / 原片（照片、贴纸）；画面上有哪些字、写在什么东西上 | 拿一段"相关的"原片充数 |
| 接上句 → 交给下句 | 哪个对象把这一句交给下一句 | 空着（=硬切） |
| 镜头 | 这一拍想让观众得到什么 + 打算怎么拍。见 `references/motion.md` | 只写"推" |

## 五、2D 还是 2.5D：怎么选

- **2D（正俯视）**：需要"读"和"看清结构"的时刻，纸面像一张海报。
- **2.5D（立起来）**：东西之间有关系、有动作、有空间的时刻。
- **切换本身就是动作**：镜头压下去时印着的东西立起来（`K.standUp`），升到俯视时立着的倒回纸面（`K.foldDown`）。放在转折处最有力。
- 2D 用多了像幻灯片，2.5D 一直用就少了海报的清楚，按内容交替。

## 六、节奏

口播定了总时长，但每句画面停多久、什么时候换，是你定的：

- **在看懂的那一刻之后换**，稍等一下；早了没看懂，晚了就拖。
- **快慢要对比**：罗列快，最重的一刻给足停留。
- 新的、复杂的停久一点；回扣前面对象的可以短。
- 画面上要读的字，停得够读完。
- 冲突时按这个顺序让：情绪 > 讲清楚 > 节奏 > 视线 > 构图。

## 七、自查（任一条答不上，改表，不进代码）

1. 关掉声音只看画面，能说出这一段发生了什么变化吗？
2. 口播里的每个名词、数字、动作，画面里都有一个看得见的对象吗？没有就写"重建示意"，不放相关素材充数。
3. 每一行的比喻是从已有的东西长出来的吗？有没有凭空贴上去的、和上一行重复的？
4. 开头 2 秒凭什么让人停下来？最重的一刻标了吗，给它留时间了吗？
5. 他的照片 / 圆贴纸是陪衬，还是抢了主体？
6. 结尾用的是前面出现过的对象吗？还是只把旁白再写一遍？
7. 每一行"交给下句"的对象，都出现在下一行吗？
8. 每一行截一帧：前景、主体、背景三层都有吗？主体上有细节吗？该有的字在画面里吗？

## 八、冷读测试（表写完、写代码之前）

派一个没参与过的 agent，**只给每行的"发生什么变化"**（不给口播、比喻、意图），让它逐行写"这一下在说什么"，再答四问：

1. 哪几处最想看下去，哪几处最想划走？
2. 哪两行在讲同一件事？
3. 哪几行的比喻看得出，哪几行看不出或像硬贴上去的？
4. 结尾留下的是哪个画面？

和表里的"看懂的那一刻"对照：对不上的、想划走的、重复的、比喻看不出的都改，改完只把改过的几行再测一次。说某行"全靠字"的，不能用"有字幕"跳过：改画面。

用户说"直接做"时也照样测，交片时附上结论。片段很短时可以跳过，交片时说一声。
