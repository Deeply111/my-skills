# 动作好看、运镜和转场

吸收自 concept-short（skill-v4）的 `参考/动作.md`、`参考/镜头.md`，换成纸面立体书能直接用的写法。API 在 `references/stage.md`。

## 动画好看

| 方面 | 要做到 | 常见的毛病 |
|---|---|---|
| 曲线 | 每个动作都有加减速，到位刹得住；弹性只给该弹的东西 | 匀速滑；全片一条缓动 |
| 时间和间距 | 快的利落，慢的沉；停顿给足 | 所有动作一样长，一个接一个没呼吸 |
| 预备和跟随 | 动之前先收一下，停下后有余波 | 突然开始、突然停死 |
| 分量 | 重的慢起、重落；轻的轻、快 | 什么都一样轻 |
| 弧线 | 跳起、抛起的东西走弧线 | 直线滑过去 |
| 视线清楚 | 观众知道这一刻看哪：要看的最显眼，陪衬的错开一点或小一点 | 几样东西抢视线；或者画面里只剩一样东西在动，显得空 |
| 衔接 | 上一句的对象变形、移动、留下，交给下一句 | 换一句清一次场 |
| 活着 | 静止的时候也有一点呼吸 | 定格的死帧 |
| 统一 | 一期一套手感：同类动作用同一个 `K.xxx`，不每处自己写缓动 | 每个镜头各弹各的 |

**手感参考**：冲过头（`back.out`、`elastic`）适合翻起、落地、弹出这类有弹性的东西；字一般稳稳落定（`power3.out`），晃来晃去难读。停得久的地方，留一点小动作或镜头在走，画面就不死。

### 曲线怎么选（GSAP）

| 用途 | 曲线 |
|---|---|
| 出现、停稳 | `power2.out` – `power3.out` |
| 离开、加速走 | `power2.in` |
| 来回、慢进慢出（镜头） | `sine.inOut`、`power2.inOut` |
| 冲过一点 | `back.out` |
| 真的弹 | `elastic.out`、`bounce.out` |
| 匀速 | 持续的运动 |

**自查**：主要动作单独 0.5 倍速看一遍（`render --fps 30` 出那一段后 `ffmpeg -i x.mp4 -vf setpts=2*PTS slow.mp4`）。手感抽帧看不出来，交片时说明哪些只看了帧。

## 运镜：四个目标

手法随这一拍定，下面只立目标：

1. **看得清**：观众始终知道看哪，字读得完，主体看得懂。读字时镜头不要快移。
2. **有理由**：每次动或不动都服务这一句的意思。
3. **有分量**：像真摄影机，不像游戏视角在飘。
4. **有变化**：整段有起伏，不一直是同一种看法；2D 和 2.5D 交替就是最大的变化。

## 转场：四个目标

1. **不迷路**：切过去后马上知道在哪、发生了什么。
2. **不断气**：动作和情绪接得上。
3. **从内容里长出来**：接法替这个转折说话，不靠滤镜效果撑场面。
4. **有松有紧**。

常见的接法：镜头一路走、同物变形、2D ↔ 2.5D 切换、动中切、切镜接着动、声音先进、镜内硬切、压暗或翻页。按这个转折选，也可以自创。

## 声音和动作对齐

- 音效对准画里**碰到的那一帧**，不是动作开始的那一帧。详见 `references/sound.md`。
- 切镜头和冲击点比配乐的拍点早一帧左右看起来才正好踩拍；音效不跟着提前。
