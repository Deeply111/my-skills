# 画风

一句话：**米白纸面上的立体书**。黑线、一个橙，所有东西都是纸片：浅色纸面、细黑边、落在纸上的影子。

## 颜色

| 用途 | 值 |
|---|---|
| 纸 / 地板 | `#F3F0E8`（带纸纹 `assets/paper.jpg` 和 300px 淡网格） |
| 纸片 | `#FBF9F4`，上亮下暗的渐变当顶光 |
| 墨 | `#141414`，线宽 4–9px |
| 强调 | `#E8430F`。给"你"、关键词、当前重点；用得越省越醒目 |
| 次要字 | `#8f8a80` |
| 侧面 | `#dcd6c9`（比正面暗一档，读出体积） |

基调是黑白纸加一个橙；需要区分两样东西时可以再加一个低饱和色，看效果。真实照片里的颜色照原样。

## 画面层次

每一镜都有三层，主体上有细节：

| 层 | 怎么处理 |
|---|---|
| 前景 | 离镜头近，只露一部分，稍暗或稍虚，不挡主体；镜头一动它移得最多 |
| 主体 | 最清楚、最亮，有细节 |
| 背景 | 远、淡、小、少对比，给空间感，不抢视线 |

放什么按这一期的内容和世界来想。

做法见 `references/stage.md`"前景和背景"。

## 字

- 中文：MiSans（Bold 做标题和关键词，Semibold 做字幕）；数字：Bebas Neue；英文小标：Montserrat。
- 画面上的字是画的一部分，长在纸上的东西上，跟着东西一起动。多少看这一句需要什么；字幕已经有全文，画面不重复整句。
- 字有大小层次：重要的大，次要的小而淡。字幕 38px，放在底部白纸条里。

### 字幕要好看（吸收自 skill-v4，用户在那边提过"字幕太丑"）

用户当时的原话：末尾有标点、全是一个颜色、没有贴着的阴影、字没和世界结合、所有字一个样子。这里逐条对上：

| 要求 | 这个模板里怎么做 |
|---|---|
| 行尾不留句号、逗号、顿号、分号、冒号；句中停顿用空格；问号、叹号留着 | `K.captions` 自动处理，稿子里照常写标点 |
| 强调词少而准，只给真要砸下去的词 | `K.captions({c03:"…"})`，橙色全片说同一件事 |
| 字幕托得住 | 白纸条 + 贴纸投影，深字浅底，不靠阴影救乱背景 |
| 有轻重、有节奏 | 逐字由灰变黑跟着念；前后两句之间留 0.16 秒空 |
| 字进世界 | 字的行为演出这句话的意思；换一期还能照用的通用飞入不算 |
| 读得完 | 画面上要读的字停得够读完；读字时镜头别快移 |
| 一行放得下 | 字幕一行最多约 22 字（38px 在 1920 宽里）；更长的在稿子里拆成两行（两条字幕） |

## 主持人（他）

- **不抠像**。只用带框的原片：白边照片、圆形贴纸（`.photo.round`）。
- **框要稳**（你定的）：默认平放在屏幕层（`.hud`），不跟镜头转，用 `K.presenterIn/Out` 轻轻淡入淡出；不做花哨的翻、飞、弹和大幅移动。
- **框的 2.5D 少用**：让他站进纸面场景是偶尔的特别处理，有理由才用，进去以后也保持安静。
- 放在不压主体和字幕的地方；照片和贴纸的位置、大小要有变化。
- 他是陪衬，不是主体：一期里有时在、有时不在（纯动画段不出现），大小和位置每次换一种。
- 照片/贴纸里的 `<video>` 用 left/top/width 调，让脸落在框里舒服的位置。

## 容易做坏的

- 空：像没做完的草图。
- 乱：东西和字堆满，不知道看哪。
- PPT：整屏大字、标题加列表。
- 换来换去：前后接不上。
- 拖：没东西可演还停着、慢推凑时长。
