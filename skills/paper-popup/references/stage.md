# 舞台、镜头和动作（lib/stage3d.js + lib/kit.js）

## 世界坐标

- 单位是像素，1920×1080 的画面。x 向右；z 朝向观众（越远越负）；地板在 y = 800（`Stage3D.FLOOR`）。
- 地板是 `#page`：一张 7500×4600 的纸，世界 x 从 -1500 到 6000，z 从 +1200 到 -3400。远处有一面虚化的背景墙（z = -3300）。
- 每一镜在地板上占一块地方，彼此隔开，镜头在它们之间移动，换场就是一次运镜。
- 所有纸片都放在 `#page` 里，用下面三个函数摆位置（它们只设位置和朝向，动画另外用 GSAP 加）：

| 函数 | 摆成什么 | 参数 |
|---|---|---|
| `K.stand(el, x, z, w, h, {yaw})` | 立着的纸片，底边中心落在 (x,z) | yaw：绕竖轴转（度），朝向镜头稍微侧一点更有立体感 |
| `K.flat(el, x, z, w, d)` | 平躺在纸面上（影子、印在纸上的东西） | — |
| `K.side(el, x, zNear, zFar, h)` | 沿纵深立着（盒子、台阶的侧面） | — |
| `K.block(parent, x, z, w, d, h, frontBg)` | 纸盒：正面 + 顶面 + 右侧面 | 有体积的东西 |

立着的纸片在 GSAP 里：`rotationX` 0 = 平躺，90 = 立起；`z` 负 = 离地往上；`x` = 沿地板左右；`y` 正 = 往远处挪。

## 前景和背景

- 三层都用同一套 `K.stand / K.flat / K.block` 摆在 `#page` 里，靠离镜头的远近分层，镜头一动自然有视差。
- **背景**：放在主体后面（z 更负），颜色浅、线细、对比低。
- **前景**：放在主体和镜头之间（z 更大），偏画面边缘，只露一部分；压暗或模糊只加在这张单独的纸片上（见"已知坑"）。
- **正俯视（2D）时**：离地抬高（z 负）的纸片就是前景，纸面本身和上面淡印的东西是背景。
- 主体的细节直接做在纸片的 HTML / CSS / SVG 里。

## 动作（kit.js）

| 动作 | 用法 | 什么时候用 |
|---|---|---|
| `K.popUp(el, t, d)` | 从纸面翻起来（立体书） | 东西登场 |
| `K.foldDown(el, t, d)` | 倒回纸面并隐藏 | 东西离场、换场前清场 |
| `K.printFlat(el, t)` | 印在纸面上、从上往下读得正 | 2D 段里的字 |
| `K.standUp(el, t)` | 从印着翻成立着 | 2D → 2.5D 的切换 |
| `K.fadeIn(el, t)` | 淡入 | 影子、平铺件 |
| `K.actor(el, inner, shadow, x, z)` | 角色，返回 `{at, hop, squash}` | `hop(t, X, Z, 抬多高, 用时, 落点高度)` |
| `K.presenterIn / Out(el, t)` | 主持人照片 / 圆贴纸轻轻淡入淡出（屏幕层） | 他出现、离开 |
| `K.bgBlock / K.bgCard` | 背景的纸盒、纸卡（浅、细线、低对比） | 每一镜的背景层 |
| `K.fgCard / K.fgFlat(…, lift)` | 前景的纸片（暗、虚）；`lift` 让它悬在纸面上方 | 每一镜的前景层；俯视时用悬空的 |
| `K.tag(text, x, z, w, h, {acc, yaw, lift})` | 立着的字牌，之后 `K.popUp` | 画面上的关键词、标签 |
| `K.print(text, x, z, w, h)` | 印在纸面上的字，之后 `K.printFlat` | 俯视段的字 |
| `K.arrow(x0, x1, z)` + `K.drawIn(el, t)` | 纸面上的虚线箭头，从起点画出来 | 方向、该有的去向 |
| `K.dropIn(g, t)` | 纸盒从上方落下（不在 3D 组上加透明度） | 有体积的东西登场 |
| `K.mk(cls, html)` | 在纸面上建一个元素，自己摆 | 其他 |
| `K.word("c03", "循")` | 第 c03 句里"循"字开口的秒数 | **所有时刻都用它取，不手填秒数** |
| `K.captions({c01:"关键词"}, 结束时刻)` | 底部字幕，关键词变橙 | 每期一次 |

镜头震动：`shake: [[时刻, 强度, 时长]]`。

## 镜头

`Stage3D.install(tl, { duration, cam: [[t, {x,y,z,rx,ry,s}, 缓动], ...], shake })`

- `x,y,z`：画面中心对准的世界点；`rx`：俯仰（-88 左右是正俯视 = 2D，绝对值越小越平视）；`ry`：水平绕；`s`：推拉。
- 关键帧之间默认两头缓（`io`），可写 `out`（冲上去停住，适合"推一下"）、`in`、`lin`（匀速，适合段落里的慢慢移动）、`hold`（到点硬切）。
- 镜头带一点手持晃动（自动）。
- 正俯视时焦点 y 设成地板高度（800），`s` 决定看多大一片。

## 已知坑

- **滤镜和半透明会把 3D 拍扁**：`filter`、`opacity < 1` 放在有 3D 子元素的容器上，子元素会被压成平面。只给"叶子"元素（单张纸片、影子）加；装纸片的容器用 `.g3`（preserve-3d）。
- **平铺的字是反的**：躺在纸面上的文字要 `rotationX: 180`（`K.printFlat` 已处理），不然读出来是镜像。
- **翻起前先藏好**：立着的纸片在 `popUp` 之前是平躺的，会以倒影的样子露在地上；`K.popUp` 会在翻起前隐藏，自己写翻起时也要 `autoAlpha`。
- **连续轨迹**（绕圈之类）用 onUpdate 算位置时，用 `tl.time()` 判断只在那一段生效，否则往回拖时会把前面的位置覆盖掉。
- 角色的翻转写在内层 `.actorIn` 的 `rotation` 上；外层管位置和高度。
