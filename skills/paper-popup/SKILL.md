# 纸面立体书（paper-popup）

把一段口播做成纸面上的立体书动画。抽象概念换成会动的纸片，一个贯穿全片的角色当"你"。字和纸片一起长在纸面上，靠东西、动作和字一起讲。

成片样例：`examples/ep02-opening/`（前 13 秒）和 `examples/ep02-part2/`（接着的 13–25 秒），各有动作表、代码、字幕和音效表。

## 宗旨（吸收自 concept-short）

做出观众轻松看、想看下去、看完有收获的画面。所有手法只为五件事，有先后：

1. **好看**（前提）：随便截一帧都舒服，动起来也舒服（`references/motion.md`）。
2. **停下来**：刷到时开头 2 秒不划走。
3. **看得懂**：比喻一眼明白，不费力。
4. **有感觉**：心里一沉、一紧。
5. **带走一个画面**：过几天还记得。

**取舍**：每加一样手法，先问它服务哪一条，答不上来就不加。加和减都是手段：空了就丰富，乱了就减。这个 skill 里没有写死的数字和配额，参考文档里的数都是起点，按这一句、这一镜的效果判断。

## 流程（按顺序，不跳步）

1. **确认范围**：哪条口播、从几秒到几秒、逐字稿（没有就先用识别结果让用户确认）。片子长时，先做开头 15–20 秒当样（就是成片质量），用户认了再铺全片。
2. **建一期**：`scripts/new_episode.py`（拷模板、截口播画面和人声、配乐、填片长）。见 `references/pipeline.md`。
3. **出逐字时间**：`scripts/make_caps.py` → `data/caps.js`。对上率低于八成先改稿子。
4. **写逐句动作表**：`action-table.md`（新建时已拷进本期目录）。先读口播（主旨、开头 2 秒、最重的一刻），定贯穿的对象，再逐句写比喻从哪长出来、变化、看懂的那一刻、交给下句、镜头。自查过了，**冷读测试**（派一个没参与的 agent 只看"发生什么变化"），改完才写代码。写法：`references/action-table.md`。
   - 用户要先看方向时，把动作表给他看；他说"直接做"就自己判断，接着做，交片时附上动作表和冷读结论。
5. **写场景**：在 `index.html` 里照动作表一行一行实现，每段注释写行号（`// A2·3`）。时刻一律用 `K.word("c02","早")`，不手填秒数。舞台、镜头、动作的 API：`references/stage.md`；动作手感、运镜和转场：`references/motion.md`；画风和字幕：`references/style.md`。
6. **看帧**：`npx hyperframes snapshot --at …`，每行至少一帧、2D/2.5D 切换前后各一帧，自己逐张看，修完再给用户看。用户说"不用出成片"时到这一步为止，把抽帧拼图发给他。
7. **出片**：`render --fps 30`，再 `scripts/master.py` 做响度。
8. **交之前自评**：按第一次刷到的观众看一遍，按五条宗旨写最差的三处、预测用户会怎么说；成片再派一轮独立审片（`references/review.md`）。发文件，说清楚哪些只看了抽帧、没完整看过听过。
9. **复盘**：用户的意见照抄进本期 `复盘.md`，挖到哪一步出的问题；要改 skill 的列成方案，用户点头才改。

## 要达到的效果

按效果判断，不按条数和次数判断。

- **每一镜都有前景、主体、背景三层**（你定的）：前景离镜头近、只露一部分；主体是这一句在演的东西；背景在远处、淡下去。三层一起动，镜头一走就出纵深。
- **主体上要有细节**（你定的）：近看也撑得住，不是一块光秃秃的纸片。
- **丰富但视线不乱**：随便截一帧都像一页做得用心的立体书；观众始终知道这一刻该看哪，陪衬的层淡一点、小一点。
- **字是画面的一部分**：画面上的字长在纸上的东西上，跟着东西一起动。字多字少看这一句需要什么；不做整句上屏、PPT 式的标题加列表。
- **比喻看得懂**：抽象的话变成纸上看得见的东西和变化，最好从画面里已有的东西长出来；同一个东西贯穿下去，比一句换一个图标好懂。
- **有纵深、有变化**：2D（正俯视，像海报）和 2.5D（立起来的场景）交替用，切换本身就是转折。用多少、什么时候切，看内容。
- **动起来舒服**：有轻重、有快慢、有呼吸；该同时动的同时动，该让视线跟着一样东西的就让开（`references/motion.md`）。
- **声音像这个世界发出的**：按 `references/sound.md` 的步骤搭。
- **主持人（你定过的）**：不抠像，只用带框的原片（照片 / 圆贴纸）；框要稳，不花哨地移动，少进 3D 场景（`references/style.md`）。

## 做法上

- **先动作表，后代码**：每句画面上发生什么先想清楚再写；写的时候发现更好的，回去改表。
- 时刻用 `K.word("c02","早")` 取，不手填秒数，改了口播也不乱。

## 技术坑（这些是真的会坏）

- 平铺在纸上的字要用 `K.printFlat`，不然读出来是反的。
- 有 3D 子元素的容器上不加 filter / 半透明，会被拍扁成平面。
- 音频要写在页面里、带 id（`scripts/bake_sfx.mjs` 自动处理），脚本插进去的没声音。
- 字幕行尾的标点由 `K.captions` 自动去掉。
