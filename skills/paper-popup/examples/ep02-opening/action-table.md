# 逐句动作表 · 高认知穷人（前 13 秒）

口播：1.mp4 调色版 0–13.0 秒，定格到 13.4 秒。代码：同目录 `index.html`（字幕 `caps.js`，音效 `sfx_cues.js`）。

## 读口播

- 一句话主旨：光往里装（早起、运动、读书）只是在原地转圈；不往外输出，处境就不会变。
- 开头 2 秒靠什么停下来：书塔一本本叠得很高（懂得多），可往外的箭头是空的——"高认知"和"穷"放在同一个画面里的反差。
- 最重的一刻：A3·1"内部循环"——镜头升到正俯视，才看清小方块一直在圈里跑。
- 方位约定：往右 = 往外；高 = 懂得多；圈里 = 原地。

| 对象 | 代表什么 | 从哪来 | 怎么变 | 到哪去 |

| 书塔 | 高认知（读过的东西） | 从纸上一本本落下 | 随镜头立起 | 留在第一镜 |

| 门 | 外面（处境改变的可能） | 栅栏外弹起 | 不动 | 始终关着 |

## 自查

1. 关掉声音只看画面：塔高（懂得多）→ 箭头是空的（没输出）→ 三件事 → 只是在圈里跑 → 门关着。✔
2. 口播里的名词都有对象：高认知=书塔，向外输出=箭头，早起/运动/读书=三件东西，内部循环=圆环，基本要求=栅栏，处境=门。✔
3. 比喻都从已有的东西长出来：箭头从塔脚、格子从落地处、圆从三件东西倒下处、栅栏沿圆、门在栅栏外。✔
4. 开头靠"塔很高、箭头是空的"的反差；最重的 A3·1 停留最长、东西最少。✔
5. 照片和贴纸都只是陪衬。✔
6. 结尾用的是前面出现过的对象（小方块、栅栏、门），没有新加总结字。✔
7. 每一行的"交给下句"都在下一行的对象里出现。✔
8. 每一镜三层都有，主体有细节（书脊字、栅栏木纹、门板），每句都有字在画面里。✔
